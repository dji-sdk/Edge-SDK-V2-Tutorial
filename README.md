# Edge SDK V2 Tutorial

Developer documentation for DJI Edge SDK V2 (ESDK V2), which enables third-party IoT devices to connect to DJI ground stations via MQTT and relay data to the DJI cloud platform.

## Documentation

- Chinese(`docs/cn/`): https://developer.dji.com/doc/edge-sdk-iot-tutorial/cn/ 
- English(`docs/en/`): https://developer.dji.com/doc/edge-sdk-iot-tutorial/en/ 

### Contents

- **Basic Introduction** — ESDK overview, glossary, hardware ports, and access standards
- **Quick Start** — Development workflow, environment setup, build and run sample
- **Function Set** — RID (Remote ID) feature guide
- **API Reference** — MQTT access & authentication, RID data reporting
- **Error Code** — Error code reference
- **FAQ** — Frequently asked questions
