After completing <a href="./build-sample.html" target="_blank">Build Sample</a>, you can run the sample program to verify the complete device-to-DJI Ground Station access and data reporting workflow.

:::tip Note:
This section is for first-time access, helping you quickly verify the basic link of Connection -> Capability Set Reporting -> Receiving `result=0`. For complete protocol definitions and field descriptions, refer to <a href="../api-reference/mqtt.html" target="_blank">Access and Authentication</a> and <a href="../function-set/rid-access.html" target="_blank">RID Feature</a>.
:::

## Pre-run Preparation

- Confirm that the O4 Ground Station and the device running the sample are on the same local network. For network configuration, see <a href="./environment-prepare.html" target="_blank">Environment Setup</a>.
- Confirm that `app_id`, `app_key`, `app_license`, and `device_id` have been filled in `include/mqtt/app_info.h` and the project has been recompiled.

## Run the Sample

Execute the following in the build output directory:

```bash
./rid_report_demo
```

After the program starts, it will sequentially:

1. **Check developer information**: If the developer information in `app_info.h` is still a placeholder, the program will prompt that credentials need to be filled in.
2. **Select Broker address source**: The program prompts you to select how to obtain the Broker address (see details below).
3. **Connect to MQTT and wait for result**: On successful connection, it prints `Connected.` (corresponding to `CONNACK=0`); on connection failure, it will prompt that reconnection is being retried in the background.
4. **Automatically report capability set**: After successful connection, the sample immediately reports the capability set to the `state` Topic (`device_type=7`). Receiving `result=0` in `state_reply` indicates successful access.
5. **Display interactive menu**: The menu header shows the current connection status.

```
========== ESDK V2 Sample ==========
 Status: [Connected]
-------------------------------------
 [1] RID device
 [q] Quit
=====================================
```

### Broker Address Selection

At startup, the program prompts you to select how to obtain the Broker address:

```
==== MQTT Broker setup ====
  [1] listen UDP 18830 until a valid broadcast arrives
  [2] skip discovery, use default 192.168.50.10:1883
select [1/2]:
```

- `[1]` Listen on UDP `18830` and wait for the O4 Ground Station broadcast to automatically resolve the Broker IP. Suitable for scenarios where the IP is not fixed, such as router-based networking. After receiving the broadcast, the log will print the resolved result, for example:

  ```
  [discover] -> valid: id=BMGDNAB0010122 name=O4_Ground_Station ip=192.168.50.10 seq=270
  ```

- `[2]` Skip discovery and use the default address `192.168.50.10:1883` directly. Suitable for LAN port direct connection where the Broker address is fixed.

For broadcast packet format and discovery mechanism details, see <a href="./environment-prepare.html#broker-address-retrieval" target="_blank">Broker Address Retrieval</a>.

## Report Data

Select `[1]` from the main menu to enter the RID submenu, and report as needed:

```
----- RID device access -----
 [1] Report capability set        (state,  device_type=7) [run first]
 [2] Report one RID  target now   (events, method=rid_infos)
 [3] Report one ADS-B target now  (events, method=adsb_infos)
 [4] Start periodic report (every 2s, demo RID/ADS-B targets)
 [5] Stop periodic report
 [b] Back
```

- `[1]` Report the capability set (must be executed first to register device type).
- `[2]` Report a sample `rid_infos` data entry (drone Remote ID detection results).
- `[3]` Report a sample `adsb_infos` data entry (ADS-B aircraft detection results).
- `[4]` Start periodic reporting: batch-reports sample RID / ADS-B targets every 2 seconds (recommended reporting mode to avoid exceeding the 5 Hz rate limit).
- `[5]` Stop periodic reporting.

For field descriptions and the complete protocol, see <a href="../function-set/rid-access.html" target="_blank">RID Feature</a>.
