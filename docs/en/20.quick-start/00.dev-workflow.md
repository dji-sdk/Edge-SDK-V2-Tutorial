This section introduces the complete workflow for developing with ESDK V2. Developers should complete developer account registration, ESDK application registration, understanding the access standards, setting up the development environment, and running the sample program in order. After verifying the access link from the device to the DJI Ground Station, formal development can begin.

## Register a Developer Account

- Visit the [DJI Developer Website](https://account.dji.com/register?appId=dji_sdk&locale=en_US) to register a developer account. Be sure to carefully read the [Agreements, Terms, and Policies](https://developer.dji.com/policies/privacy) for using the DJI SDK.

- To receive convenient and efficient services, please fill in the registration information correctly.

## Understand Access Standard

Before starting development, it is recommended to first understand the technical standards and hardware specifications that a device must meet to access ESDK V2:

- <a href="../basic-intro/access-standard.html" target="_blank">Access Standard</a>: general access requirements applicable to all devices, such as network communication, capability set declaration, and message constraints.
- <a href="../basic-intro/hardware/hardware-port.html" target="_blank">Hardware Port</a> and <a href="../basic-intro/hardware/hardware-design.html" target="_blank">Hardware Design</a>: the definition of the O4 Ground Station network ports, and the hardware design constraints involved in a third-party dock, such as wireless charging, ACDC, and the flight system (a must-read when accessing a third-party dock).

## Set Up the Development Environment

After carefully reading the <a href="./environment-prepare.html" target="_blank">Environment Preparation</a> section, prepare the O4 Ground Station, access device, and network environment according to your actual development needs to complete the development environment setup.

## Verify the Sample

Refer to the <a href="./build-sample.html" target="_blank">Build Sample</a> and <a href="./run-sample.html" target="_blank">Run Sample</a> chapters to run sample workflows such as device access, capability set reporting, RID / ADS-B data reporting, dock power-on and charging, takeoff and landing coordination, dock configuration, and parameter configuration, and quickly familiarize yourself with the development process. For the specific access protocol, see the <a href="../api-reference/mqtt.html" target="_blank">API Reference</a>.
