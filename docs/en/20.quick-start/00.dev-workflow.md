This section describes the complete development workflow for ESDK V2. Developers need to sequentially complete developer account registration, ESDK application registration, development environment setup, and sample program execution. Once the device-to-DJI Ground Station access link has been verified, formal development can begin.

## Register a Developer Account

- Visit the [DJI Developer Website](https://account.dji.com/register?appId=dji_sdk&locale=en_US) to register a developer account. Please carefully read the [Terms, Policies, and Privacy](https://developer.dji.com/policies/privacy) for using the DJI SDK.

- To ensure convenient and efficient service, please fill in the registration information accurately.

## Application Registration

Go to the Developer Center - Apps page, and click **CREATE APP**.

Click **Send Email** to activate your application via email.

## Set Up the Development Environment

After carefully reading the <a href="./environment-prepare.html" target="_blank">Environment Setup</a> section, prepare the O4 Ground Station, connected devices, and network environment according to your development needs to complete the development environment setup.
