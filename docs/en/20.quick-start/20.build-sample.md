ESDK V2 provides a complete RID access sample project that demonstrates how a device connects to the DJI Ground Station via MQTT, reports its capability set, and reports RID / ADS-B information. This section describes how to obtain, configure, and build the sample.

## Get the Code Package

Obtain the sample project from the code repository:

```
git clone https://github.com/dji-sdk/Edge-SDK-V2-Demo
```

:::tip Note:
All subsequent sample commands assume the cloned project root directory as the current directory.
:::

## Project Directory Structure

The following directory structure is for reference only. Please refer to the actual code package obtained.

```
sample_esdk2/
├── CMakeLists.txt    // Build entry point (top level)
├── cmake/            // CMake modules (locating dependencies like mosquitto)
├── include/          // Cross-module public header files (common / mqtt / rid)
├── src/              // Implementation source files (common / mqtt / rid)
├── third_party/      // Third-party libraries (nlohmann/json single header file)
└── examples/         // Sample programs (rid_report_demo: entry point and interactive menu)
```

## Install Dependencies

The sample is implemented based on the mosquitto C++ client. Install the dependencies before building (using Ubuntu / Raspberry Pi as an example):

```bash
sudo apt install -y libmosquittopp-dev cmake build-essential
```

## Developer Information Authentication

1. Obtain `app_id`, `app_key`, and `app_license`. For instructions, see <a href="./dev-workflow.html#application-registration" target="_blank">Development Workflow - Application Registration</a>.
2. Modify the `include/mqtt/app_info.h` file in the sample project and fill in the corresponding developer information:

```c
#define USER_DEVICE_ID      "your_device_id"      // Device serial number
#define USER_APP_ID         "your_app_id"
#define USER_APP_KEY        "your_app_key"
#define USER_APP_LICENSE    "your_app_license"

// Optional username suffix. RID devices may exceed the 2048-byte default payload limit;
// set to "@rid" to lift the limit; leave as "" for normal scenarios.
#define USER_USERNAME_SUFFIX "@rid"
```

:::tip Note:
The sample will automatically concatenate the MQTT login information: the username / ClientID format is `{app_id}_esdk_{device_id}` + `USER_USERNAME_SUFFIX`, and the password format is `{app_key}_{app_license}`. For the complete concatenation rules, see <a href="../api-reference/mqtt.html#login-information" target="_blank">Access and Authentication - Login Information</a>.
:::

## Build the Sample Code

Execute the following in the project root directory:

```bash
mkdir build && cd build && cmake .. && make -j4
```

After the build is complete, the executable `rid_report_demo` will be generated. For instructions on running it, see <a href="./run-sample.html" target="_blank">Run Sample</a>.
