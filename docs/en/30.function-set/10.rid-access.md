ESDK V2 supports connecting third-party RID/ADS-B receiver devices to the DJI Ground Station, reporting the collected drone identification and flight status data to FlightHub 2 (DJI's enterprise cloud platform) in real time, enabling unified aggregation and visual management of airspace awareness data. This section describes the access workflow, reporting frequency limits, and FlightHub 2 visualization configuration for RID devices.

:::tip Note:
When an RID device reports its capability set, `device_type` is fixed at 7.
:::

## Feature Description

The RID device caches detected targets and reports them in batches through the events Topic. There are two types of reporting events:

| Reporting Event | Description | Command (method) |
|:---|:---|:---|
| RID information reporting | Report detected drone RID targets | rid_infos |
| ADS-B information reporting | Report detected ADS-B targets | adsb_infos |

## Access Workflow

1. **MQTT Access and Authentication**: Concatenate the login information and connect to the DJI Ground Station Broker. RID devices must append the `@rid` suffix to the end of the username to lift the payload limit. See <a href="../api-reference/mqtt.html" target="_blank">Access and Authentication</a>.
2. **Capability Set Reporting**: Report the device type and capability declaration via the state Topic. Data can only be reported after receiving result = 0. See <a href="../api-reference/capability-report.html" target="_blank">Capability Set Reporting</a>.
3. **Data Reporting**: Cache the detected RID / ADS-B targets and report them in batches. See <a href="../api-reference/rid.html#rid-information-reporting" target="_blank">RID Information Reporting</a> and <a href="../api-reference/rid.html#ads-b-information-reporting" target="_blank">ADS-B Information Reporting</a>.

## Reporting Frequency Limit

The DJI Ground Station limits the message frequency of connected devices to 5 Hz; messages exceeding the limit will be intercepted. The reporting of rid_infos and adsb_infos must follow these rules:

- Cache the detected targets and report them merged, avoiding sending them one by one.
- rid_infos and adsb_infos are each reported once every 2 seconds, merging the targets within the cache period into the corresponding rid / adsb array and sending them together.
- The two event types are independent of each other and are reported according to their own 2-second cycles respectively.

## FlightHub 2 Visualization

After an RID device connects successfully, you can view the RID devices mounted under the O4 Ground Station on the device operation and maintenance page of FlightHub 2:

<img src="https://terra-1-g.djicdn.com/71a7d383e71a4fb8887a310eb746b47f/esdk-v2/rid/device-maintenance-en.png" width="40%"/>

In the device list of FlightHub 2, the connected RID devices are also displayed under the O4 Ground Station:

<img src="https://terra-1-g.djicdn.com/71a7d383e71a4fb8887a310eb746b47f/esdk-v2/rid/flighthub-device-list-rid-en.png" width="80%"/>



The RID / ADS-B information reported by the device is forwarded to the cloud via the O4 Ground Station and can be viewed on FlightHub 2 (DJI's enterprise cloud platform). The configuration steps are as follows:

1. Enter the FlightHub 2 project and open **"Airspace Safety" → "Airspace Alerts"** in sequence.
2. Enable the **"DJI O4 Ground Station"** airspace alert.
3. In **"Identification Type"**, select the drone types for which alerts are to be displayed.
4. Set the alert distance threshold.

<img src="https://terra-1-g.djicdn.com/71a7d383e71a4fb8887a310eb746b47f/esdk-v2/rid/flighthub-o4-alert-settings-en.png" width="80%"/>

After completing the configuration, FlightHub 2 displays all RID / ADS-B drones within the alert distance threshold range on the map:

- The **center** is the gnss information in the report (i.e., the position of the reporting device itself);
- The **radius** is the configured **"alert distance threshold"**;
- All RID / ADS-B drone targets within this circular range are displayed on the map.

<img src="https://terra-1-g.djicdn.com/71a7d383e71a4fb8887a310eb746b47f/esdk-v2/rid/flighthub-rid-targets-on-map-en.png" width="80%"/>



:::tip Note:
If FlightHub 2 does not display targets, first confirm that the capability set report has returned result=0, and that rid_infos / adsb_infos are being reported normally according to the [Reporting Frequency Limit](#reporting-frequency-limit) without triggering the frequency limit.
:::
