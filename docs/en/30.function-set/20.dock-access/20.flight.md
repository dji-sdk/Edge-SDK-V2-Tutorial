ESDK V2 enables a third-party dock to work with the DJI Ground Station to complete the drone's **takeoff, landing, and mission exception recovery**. Unlike power-on and charging, Takeoff-Landing Coordination is a **downlink** process—the Ground Station issues commands to the dock, and the dock executes them and reports progress events.

:::tip Note:
The "Takeoff-Landing Coordination" referred to in this capability means the **dock works with the Ground Station** to prepare for takeoff and landing and report progress, rather than controlling the flight attitude of the drone itself. The flight control of the drone is handled by the drone itself.
:::

## Feature Description

Takeoff-Landing Coordination includes five stages, covering the three scenarios of takeoff, landing, and exception recovery. After the Ground Station issues a services command, the dock responds and reports the execution progress through event until completion:

| Stage | Description | Command / Event Report (method) |
|:---|:---|:---|
| Takeoff preparation | Preparation before drone takeoff | airport_takeoff_prepare |
| Takeoff end | Drone takeoff completion | airport_takeoff_end |
| Landing preparation | Preparation before drone landing | airport_landing_prepare |
| Landing end | Drone landing completion | airport_landing_end |
| Mission exception recovery | Recovery handling when an operation exception occurs | airport_abnormal_recovery |

:::tip Note:
The `method` of the event report is the same as the `method` of the issued command. The message type is distinguished by the Topic (services / events).
:::

## Access Workflow

Takeoff-Landing Coordination belongs to the third-party dock capability domain:

1. **MQTT access and authentication**. See <a href="../../api-reference/mqtt.html" target="_blank">Access and Authentication</a> for details.
2. **Capability Set Reporting** (`device_type = 5`). See <a href="../../api-reference/capability-report.html" target="_blank">Capability Set Reporting</a> for details.
3. **Subscribe to the services Topic** to receive Takeoff-Landing Coordination commands issued by the Ground Station.
4. **Respond and report progress**: After receiving services, reply with services_reply, then report the execution progress through event.
