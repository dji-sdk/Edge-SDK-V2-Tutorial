ESDK V2 provides configuration capabilities for third-party docks, including network configuration, image transmission (SDR) supported drone models, cloud parameters, and organization binding. All are actively initiated by the third-party dock to the DJI Ground Station.

## Access Workflow

Dock Configuration belongs to the third-party dock capability domain:

1. **MQTT access and authentication**. See <a href="../../api-reference/mqtt.html" target="_blank">Access and Authentication</a> for details.
2. **Capability Set Reporting** (`device_type = 5`). See <a href="../../api-reference/capability-report.html" target="_blank">Capability Set Reporting</a> for details.
3. **Issue configuration commands**: Publish the corresponding command to the requests Topic and obtain the result from requests_reply.
