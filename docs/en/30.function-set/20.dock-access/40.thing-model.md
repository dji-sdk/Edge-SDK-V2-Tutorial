ESDK V2 provides the capability to read and write the dock's thing model (TSL) properties: reading the dock's real-time status (work mode, return-to-home point, battery, charger status, etc.) and setting writable properties in batches. It is actively initiated by the third-party dock to the DJI Ground Station.

## Feature Description

Parameter Configuration works in two directions, query and set, both actively initiated by the third-party dock to the DJI Ground Station:

| Operation | Description | Command (method) |
|:---|:---|:---|
| Query thing model parameters | Reads the dock's current thing model property values | get_tsl_params |
| Set thing model parameters | Sets a group of writable properties in batches; only the properties submitted this time are updated | set_tsl_params |

The thing model properties cover the return-to-home point, alternate landing point, base station work mode, drone in-place/power-on status, charging status, battery information, etc. For the complete property table, see the API Reference section.

## Configurable Parameters

The thing model properties that can be set through `set_tsl_params` (with `read_write` permission) are listed below. Other status properties are read-only and reported by the gateway. For the complete property table, see <a href="../../api-reference/dock/thing-model.html#thing-model-parameter-table" target="_blank">API Reference - Parameter Configuration</a>:

| Property | Function | Type |
|:---|:---|:---|
| drone_home_point_longitude | Drone home point longitude | double |
| drone_home_point_latitude | Drone home point latitude | double |
| drone_home_point_height | Drone home point height | double |
| drone_alternate_land_point_longitude | Drone alternate landing point longitude | double |
| drone_alternate_land_point_latitude | Drone alternate landing point latitude | double |
| drone_alternate_land_point_height | Drone alternate landing point height | double |
| station_work_mode | Base station work mode (0: roaming; 1: external dock; 2: simple airport) | int |
| third_dock_work_mode | Third-party dock mode, which must be set to 1 when accessing a third-party dock | int |

:::tip Note:
- The home point and alternate landing point only need to be set once during dock deployment, unless the dock is moved.
- For `double` type fields such as longitude, latitude, and height, do not pass integer values; otherwise, the decimal part will be truncated, resulting in incorrect position data.
:::

## Access Workflow

Parameter Configuration belongs to the third-party dock capability domain:

1. **MQTT access and authentication**. See <a href="../../api-reference/mqtt.html" target="_blank">Access and Authentication</a> for details.
2. **Capability Set Reporting** (`device_type = 5`). See <a href="../../api-reference/capability-report.html" target="_blank">Capability Set Reporting</a> for details.
3. **Query / set thing model parameters**: Publish `get_tsl_params` or `set_tsl_params` to the requests Topic.

:::tip Note:
When accessing a third-party dock, the thing model property `third_dock_work_mode` must be set to 1.
:::
