After a device connects to the DJI Ground Station via MQTT and completes authentication, it must first report its capability set once, declaring its own type and supported capabilities via `device_type`. This is the first step after any device connects: the DJI Ground Station identifies the device based on this, and only after the capability set is reported successfully can the device proceed with subsequent data reporting and command interaction.

## Reporting Workflow

1. **Establish MQTT connection**: Concatenate the login information and connect to the DJI Ground Station Broker. See <a href="../api-reference/mqtt.html" target="_blank">Access and Authentication</a>.
2. **Subscribe to the reply Topic**: Subscribe to `state_reply` to receive the capability set reporting result.
3. **Report the capability set**: Report `device_type` and `capabilities` via the `state` Topic.
4. **Confirm the result**: Wait for `state_reply` to return `result = 0`, indicating the capability set has taken effect. Only then can messages of each capability domain be delivered / reported.

:::warning Note:
A single device can only declare one `device_type` and cannot connect as multiple identities simultaneously. Choose the corresponding access method based on your device type: for RID, see <a href="./rid-access.html" target="_blank">RID device</a>; for third-party dock, see <a href="./dock-access/charging.html" target="_blank">Third-Party Dock Device</a>.
:::
