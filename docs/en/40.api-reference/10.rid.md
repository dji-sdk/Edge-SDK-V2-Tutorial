This section defines the interfaces involved in RID device access to ESDK V2, including the payload structures and field descriptions for Payload Extension, RID Information Reporting, and ADS-B Information Reporting.

:::tip Note:
After an RID device connects, it must first complete capability set reporting (`device_type = 7`). Only after result = 0 is returned can the following RID / ADS-B events be reported. See <a href="./capability-report.html" target="_blank">Capability Set Reporting</a>.
:::

## Payload Extension

A single RID device events report can reach approximately 20 KB, exceeding the DJI Ground Station's default payload limit of 2048 bytes. When connecting, the `@rid` suffix must be appended to the end of the MQTT username to lift the limit (the rest of the login information remains unchanged; for the complete concatenation rules, see <a href="./mqtt.html#login-information" target="_blank">Access and Authentication - Login Information</a>).

| Login Information | Concatenation Rule |
|:---|:---|
| username | `{app_id}_esdk_{device_id}@rid` |
| password | Same as standard access, no modification needed |

## Common Fields

The following fields are common top-level fields for all reporting messages and are not repeated in the field descriptions of each interface.

| Field | Type | Required | Description |
|:---|:---|:---|:---|
| bid | string | Yes | Business ID, non-empty. |
| tid | string | Yes | Transaction tracking ID, non-empty. |
| timestamp | integer | Yes | Millisecond timestamp, ≥ 0. |
| version | string | Yes | Protocol version, fixed at 1.0.0. |
| method | string | No | Method identifier.<ul><li>Required for events reporting: <code>rid_infos</code> for RID reporting, <code>adsb_infos</code> for ADS-B reporting.</li><li>Not present in state reporting.</li></ul> |
| data | object | Yes | Message data body. |

## RID Information Reporting

### Payload Example

- **Topic**: `thing/product/{client_id}/events`
- **Direction**: Device → DJI Ground Station
- **QoS**: 1
- **method**: `rid_infos`

```json
{
  "tid": "UUID-TRACK-YYYY-YYYY",
  "bid": "UUID-CAPS-XXXX-XXXX",
  "timestamp": 1757400927326,
  "method": "rid_infos",
  "version": "1.0.0",
  "data": {
    "capacity_percent": 48,
    "power_supply": 0,
    "gnss": {
      "engine": 0,
      "flag": 2,
      "time": "20250723-142355",
      "lat": 22.58821,
      "lon": 113.50389,
      "alt": 503,
      "satellite": 5,
      "hdop": 5
    },
    "rid": [
      {
        "osid": "1581F6N8C243L0039TB9",
        "rssi": -79,
        "fre": 1,
        "uatype": 2,
        "status": 0,
        "heading": 12,
        "speed": 5.4,
        "uprate": 1.5,
        "lon": 113.22128,
        "lat": 22.58079,
        "altgeo": 120,
        "altbaro": 120,
        "height": 50,
        "op_lon": 113.22322,
        "op_lat": 22.58475,
        "op_alt": 20,
        "uatime": 174462011
      }
    ]
  }
}
```

### Field Description

For the common fields at the top level of the message, see [Common Fields](#common-fields). The following are the fields within data:

<div class="collapsible" />

| Field | Type | Required | Description |
|:---|:---|:---|:---|
| capacity_percent | integer | No | Remaining battery percentage of the reporting device, value range [0, 100]. |
| power_supply | integer | No | Power supply type identifier. The current protocol does not define specific value meanings. Contact DJI Technical Support if needed. |
| gnss | object | No | Positioning information of the reporting device itself. |
| >>engine | integer | No | Positioning engine.<ul><li>0: Hybrid positioning</li><li>1: GPS system</li><li>2: BeiDou system</li></ul> |
| >>flag | integer | No | Positioning flag.<ul><li>0: Not positioned</li><li>1: SPS mode</li><li>2: Differential mode</li><li>3: PPS mode</li></ul> |
| >>time | string | No | UTC time, format: YYYYMMDD-HHMMSS (e.g., `20250723-142355`). |
| >>lat | number | No | Latitude. |
| >>lon | number | No | Longitude. |
| >>alt | number | No | Altitude. |
| >>satellite | integer | No | Number of positioning satellites. |
| >>hdop | number | No | Horizontal Dilution of Precision. |
| rid | array&lt;object&gt; | No | List of drone Remote ID targets detected in this report. |
| >>osid | string | No | Drone ID. |
| >>rssi | number | No | Signal strength. Higher values indicate stronger signal. |
| >>fre | integer | No | Communication channel.<ul><li>0: WIFI 5.8G</li><li>1: WIFI 2.4G</li><li>2: Bluetooth</li></ul> |
| >>uatype | integer | No | Drone type.<ul><li>0: Unknown/other</li><li>1: Fixed-wing aircraft</li><li>2: Drone/multi-rotor</li><li>3: Helicopter/rotorcraft</li><li>4: VTOL fixed-wing</li><li>5: Paraglider/paramotor</li><li>6: Glider</li><li>7: Kite</li><li>8: Balloon</li><li>9: Captive balloon</li><li>10: Airship</li><li>11: Parachute (unpowered)</li><li>12: Rocket</li><li>13: Tethered powered aircraft</li><li>14: Ground obstacle</li><li>15: Other</li></ul> |
| >>status | integer | No | Flight status.<ul><li>0: Unknown</li><li>1: Ground</li><li>2: Airborne</li><li>3: Emergency</li></ul> |
| >>heading | number | No | Track angle. 361 indicates unknown or hovering status. |
| >>speed | number | No | Horizontal speed of the drone, in m/s. |
| >>uprate | number | No | Vertical speed of the drone, in m/s. |
| >>lon | number | No | Longitude of the drone. |
| >>lat | number | No | Latitude of the drone. |
| >>altgeo | number | No | Geodetic altitude of the drone. -1000 indicates unknown. |
| >>altbaro | number | No | Barometric altitude of the drone. -1000 indicates unknown. |
| >>height | number | No | Height above ground of the drone. -1000 indicates unknown. |
| >>op_lon | number | No | Operator position longitude. |
| >>op_lat | number | No | Operator position latitude. |
| >>op_alt | number | No | Operator position altitude, in meters. |
| >>uatime | number | No | Internal time of the drone. |

:::warning Note:
gnss describes the position of the reporting device itself; lat / lon / op_lat / op_lon in `rid[]` describe the positions of the detected drone and its operator. These two must not be confused.
:::

## ADS-B Information Reporting

### Payload Example

- **Topic**: `thing/product/{client_id}/events`
- **Direction**: Device → DJI Ground Station
- **QoS**: 1
- **method**: `adsb_infos`

```json
{
  "tid": "4fad3f06-a84e-476a-ba31-1ba330fd5865",
  "bid": "602c4276-f28f-42f9-ab30-4a85072140f5",
  "timestamp": 1777348300100,
  "method": "adsb_infos",
  "version": "1.0.0",
  "data": {
    "capacity_percent": 48,
    "power_supply": 0,
    "gnss": {
      "engine": 0,
      "flag": 2,
      "time": "20260428-035140",
      "lat": 22.793106,
      "lon": 114.358677,
      "alt": 40.9,
      "satellite": 12,
      "hdop": 5
    },
    "adsb": [
      {
        "icao": "781EB7",
        "callsign": "CSN1735",
        "height": 11003,
        "lat": 22.58821,
        "lon": 113.50389,
        "speed": 941,
        "heading": 185,
        "uprate": 0.32
      }
    ]
  }
}
```
