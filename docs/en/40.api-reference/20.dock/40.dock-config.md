This section defines the MQTT interfaces related to third-party dock configuration, including network configuration, image transmission drone model settings, and cloud connection configuration.

:::tip Note:
After a third-party dock is connected, it must first complete Capability Set Reporting (`device_type = 5`). Only after result = 0 is returned can the following configuration commands be issued. For details, see <a href="../capability-report.html" target="_blank">Capability Set Reporting</a>.
:::

## Protocol Description

The Topics involved in the interfaces are as follows:

| Type | Direction | Topic |
|:---|:---|:---|
| Request | Third-party dock → DJI Ground Station | thing/product/{client_id}/requests |
| Reply | DJI Ground Station → Third-party dock | thing/product/{client_id}/requests_reply |

The interfaces provided in this section are as follows:

| Operation | method |
|:---|:---|
| Set network configuration | set_network_params |
| Get network configuration | get_network_params |
| Set drone types supported by image transmission | set_sdr_firmware |
| Get drone types supported by image transmission | get_sdr_firmware |
| Cloud connection configuration | set_cloud_params |
| Cloud connection binding | airport_organization_bind |

## Common Fields

The following fields are common top-level fields for all messages and are not repeated in individual interface field descriptions.

| Field | Type | Required | Description |
|:---|:---|:---|:---|
| bid | string | Yes | Business ID, non-empty. |
| tid | string | Yes | Transaction tracking ID, non-empty. |
| timestamp | integer | Yes | Millisecond timestamp, ≥ 0. |
| version | string | Yes | Protocol version, fixed at 1.0.0. |
| method | string | Yes | Method identifier. |
| data | object | Yes | Message data body. |
| gateway | string | No | Appears only in the response (requests_reply). Its value is the serial number gateway_sn of the O4 Ground Station (gateway) that processed the request, filled in by the Ground Station to identify the response source. |

## Set Network Configuration

### Request Payload Example

- **Topic**: `thing/product/{client_id}/requests`
- **Direction**: Third-party dock → DJI Ground Station
- **method**: `set_network_params`

```json
{
  "bid": "UUID-CAPS-XXXX-XXXX",
  "tid": "UUID-TRACK-YYYY-YYYY",
  "data": {
    "dynamic_ip": true,
    "static_ip_conf": {
      "static_ip": "192.168.1.101",
      "netmask": "255.255.255.0",
      "default_gateway": "192.168.1.1",
      "pri_dns_ip": "192.168.1.100",
      "sec_dns_ip": "192.168.1.100"
    }
  },
  "method": "set_network_params",
  "version": "1.0.0",
  "timestamp": 1757400927326
}
```

### Request Field Description

For top-level fields, see <a href="#common-fields">Common Fields</a>. The `data` fields are described below:

<div class="collapsible" />

| Field | Type | Description |
|:---|:---|:---|
| dynamic_ip | bool | Whether to use dynamic IP (DHCP). |
| static_ip_conf | object | Static IP configuration (takes effect when dynamic_ip = false). |
| >>static_ip | string | Static IP address. |
| >>netmask | string | Subnet mask. |
| >>default_gateway | string | Default gateway. |
| >>pri_dns_ip | string | Primary DNS address. |
| >>sec_dns_ip | string | Secondary DNS address. |

### Response Payload Example

- **Topic**: `thing/product/{client_id}/requests_reply`
- **Direction**: DJI Ground Station → Third-party dock

```json
{
  "bid": "UUID-CAPS-XXXX-XXXX",
  "data": { "result": 0 },
  "method": "set_network_params",
  "tid": "UUID-TRACK-YYYY-YYYY",
  "timestamp": 1773816352073,
  "version": "1.0.0",
  "gateway": "gateway_sn"
}
```

### Response Field Description

For top-level fields, see <a href="#common-fields">Common Fields</a>. The `data` fields are described below:

| Field | Type | Description |
|:---|:---|:---|
| result | int | Request result. Non-zero indicates an error. |

For top-level fields, see <a href="#common-fields">Common Fields</a>. The `data` fields are described below:

## Cloud Connection Configuration

### Request Payload Example

- **Topic**: `thing/product/{client_id}/requests`
- **Direction**: Third-party dock → DJI Ground Station
- **method**: `set_cloud_params`

```json
{
  "bid": "UUID-CAPS-XXXX-XXXX",
  "tid": "UUID-TRACK-YYYY-YYYY",
  "data": {
    "cloud_type": 0,
    "mqtt_url": "",
    "mqtt_account": "",
    "mqtt_password": ""
  },
  "method": "set_cloud_params",
  "version": "1.0.0",
  "timestamp": 1757400927326
}
```

### Request Field Description

For top-level fields, see <a href="#common-fields">Common Fields</a>. The `data` fields are described below:

<div class="collapsible" />

| Field | Type | Description |
|:---|:---|:---|
| cloud_type | int | Cloud connection type.<ul><li>0: FlightHub 2</li><li>1: Third-party cloud</li><li>2: FlightHub 2 On-Premises</li></ul> |
| mqtt_url | string | Cloud connection MQTT address. Required only when cloud_type=1 or 2. |
| mqtt_account | string | MQTT account. Required only when cloud_type=1. |
| mqtt_password | string | MQTT password. Required only when cloud_type=1. |

### Response Payload Example

- **Topic**: `thing/product/{client_id}/requests_reply`
- **Direction**: DJI Ground Station → Third-party dock

```json

  "method": "set_cloud_params",
  "tid": "UUID-TRACK-YYYY-YYYY",
  "timestamp": 1773816352073,
  "version": "1.0.0",
  "gateway": "gateway_sn"
}
```

### Response Field Description

For top-level fields, see <a href="#common-fields">Common Fields</a>. The `data` fields are described below:

| Field | Type | Description |
|:---|:---|:---|
| result | int | Request result. Non-zero indicates an error. |
