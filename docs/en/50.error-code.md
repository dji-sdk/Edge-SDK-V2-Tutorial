This section lists the error codes that may occur during the process of a device accessing the DJI Ground Station, along with their meanings and corresponding solutions.

## MQTT Connection Error Codes

When a device connects to the DJI Ground Station MQTT Broker, the Broker returns the connection result through a CONNACK packet:

| Return Code | Meaning | Solution |
|:---:|:---|:---|
| 0 | Connection accepted | Normal flow; you can start subscribing to Topics and reporting data. |
| 1 | Unacceptable protocol version | Check whether the protocol version used by the MQTT client is compatible with the Broker. |
| 2 | Identifier rejected | Check whether the ClientID is valid (non-empty and compliant with the concatenation rules). |
| 3 | Service unavailable | The DJI Ground Station service is temporarily unavailable; retry later. |
| 4 | Malformed username or password | Check whether the concatenation format of the username and password is correct. |
| 5 | Authentication failed | Validation of app_id / app_key / app_license failed; verify the authentication information. |

## ACL Authentication Error Codes

After a device accesses the network, the DJI Ground Station performs ACL validation on the subscribed / published Topics and reported messages. When validation fails, the following error codes (in decimal) are returned:

| Error Code | Meaning | Solution |
|:---|:---|:---|
| 16843008 | Unknown authentication failure | Retry the connection; if it keeps failing, verify the account and Topic configuration. |
| 16843009 | Topic mismatch | Check whether the Topic complies with the `thing/product/{client_id}/...` rule. |
| 16843010 | The client_id in the Topic does not match the account | Confirm that `{client_id}` is exactly the same as the login account (`{app_id}_esdk_{device_id}`). |
| 16843011 | The subscribed Topic is not in the allowed range | Only subscribe to the Topics listed in the documentation, such as state_reply / events_reply / requests_reply / services / error. |
| 16843012 | The published Topic is not in the allowed range | Only publish the Topics listed in the documentation, such as state / events / requests / osd / services_reply. |
| 16843013 | Topic QoS mismatch | Set the QoS as required by the documentation (e.g., use QoS 1 for state / events). |
| 16843265 | Message frequency exceeded | The reporting frequency exceeds 5 Hz; reduce the reporting frequency. |
| 16843266 | Message length exceeded | A single message exceeds 2048 bytes; reduce the payload size. RID devices can remove the payload limit by appending the `@rid` suffix to the end of the username (see <a href="./api-reference/rid.html#payload-extension" target="_blank">Payload Extension</a>); this mechanism is not available for docks and other devices. |
