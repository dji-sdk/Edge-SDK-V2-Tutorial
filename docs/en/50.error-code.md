This section lists the error codes, meanings, and corresponding solutions that may be encountered when devices connect to the DJI Ground Station.

## MQTT Connection Error Codes

When a device connects to the DJI Ground Station MQTT Broker, the Broker returns the connection result via a CONNACK packet:

| Return Code | Meaning | Solution |
|:---:|---|---|
| 0 | Connection successful | Normal flow. You can begin subscribing to Topics and reporting data. |
| 1 | Unacceptable protocol version | Check whether the MQTT protocol version used by the client is compatible with the Broker. |
| 2 | Identifier rejected | Check whether the ClientID is valid (non-empty and follows the concatenation rules). |
| 3 | Server unavailable | The DJI Ground Station service is temporarily unavailable. Retry later. |
| 4 | Bad username or password format | Check whether the username and password concatenation format is correct. |
| 5 | Authentication failed | app_id / app_key / app_license validation failed. Verify the authentication information. |

## ACL Authorization Error Codes

After device access, the DJI Ground Station performs ACL validation on the Topics subscribed/published and the reported messages. The following error codes (decimal) are returned on validation failure:

| Error Code | Meaning | Solution |
|---|---|---|
| 16843008 | Unknown authorization failure | Retry the connection. If the failure persists, verify the account and Topic configuration. |
| 16843009 | Topic mismatch | Check whether the Topic follows the `thing/product/{client_id}/...` rule. |
| 16843010 | client_id in Topic does not match the account | Confirm that `{client_id}` exactly matches the login account (`{app_id}_esdk_{device_id}`). |
| 16843011 | Subscribed Topic not in the allowed range | Only subscribe to the Topics listed in the documentation: state_reply / events_reply / requests_reply / services / error, etc. |
| 16843012 | Published Topic not in the allowed range | Only publish to the Topics listed in the documentation: state / events / requests / osd / services_reply, etc. |
| 16843013 | Topic QoS mismatch | Set the QoS as specified in the documentation (e.g., state / events use QoS 1). |
| 16843265 | Message rate exceeded | The reporting rate exceeds 5 Hz. Reduce the reporting rate. |
| 16843266 | Message length exceeded | A single message exceeds 2048 bytes. Reduce the payload size or lift the payload limit through device type declaration. |
