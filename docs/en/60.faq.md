This section summarizes frequently asked questions and solutions when devices connect to the DJI Ground Station via MQTT.

<table>
  <thead>
    <tr>
      <th style="text-align: center;">No.</th>
      <th>Symptom</th>
      <th>Cause</th>
      <th>Solution</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td style="text-align: center;">1</td>
      <td>Connection returns CONNACK=5</td>
      <td>app_id, app_key, or app_license validation failed, or the username/password concatenation format is incorrect</td>
      <td>Verify the authentication information. The username format is <code>{app_id}_esdk_{device_id}</code>, and the password format is <code>{app_key}_{app_license}</code>. For details, see <a href="./api-reference/mqtt.html#login-information" target="_blank">Access and Authentication - Login Information</a>.</td>
    </tr>
    <tr>
      <td style="text-align: center;">2</td>
      <td>Connection timeout / unable to connect</td>
      <td>Not connected to the correct Broker, or the device and the O4 Ground Station are not on the same subnet</td>
      <td>Confirm the Broker IP (see <a href="./quick-start/environment-prepare.html#broker-address-retrieval" target="_blank">Broker Address Retrieval</a>); check the IP subnet and port 1883.</td>
    </tr>
    <tr>
      <td style="text-align: center;">3</td>
      <td>state_reply returns a non-zero result</td>
      <td>The capability set payload is invalid, or required fields such as device_type are incorrect</td>
      <td>Verify the required fields in the capability set payload. The device_type must match the device type. For details, see <a href="./api-reference/rid.html#capability-set-reporting" target="_blank">RID Data Reporting - Capability Set Reporting</a>.</td>
    </tr>
    <tr>
      <td style="text-align: center;">4</td>
      <td>Error blocking notification received after event reporting</td>
      <td>1. Reporting rate exceeds 5 Hz, or a single payload exceeds 2048 bytes;<br/>2. Message format error, such as field name typos or incorrect field types.</td>
      <td>1. Reduce the reporting rate (it is recommended to cache and batch report). For large single payloads, the limit can be lifted through <a href="./api-reference/rid.html#payload-extension" target="_blank">Payload Extension</a>.<br/>2. Verify that the payload is valid JSON, and that field names, field types match the protocol definition.</td>
    </tr>
  </tbody>
</table>
