## Edge SDK V2.1.0 Release Notes

### Release Date

2026-10-14

### New Features

Added support for third-party dock device access. Together with the DJI Ground Station, the dock provides the following capabilities:
-  Power-on and charging: support access to the DJI wireless charging module, and control power on/off of the drone inside the dock, and start/stop charging.
- Takeoff and landing coordination: work with the Ground Station to complete the preparation and progress reporting for drone takeoff, landing, and mission exception recovery.
- Dock configuration: network configuration, cloud configuration, image transmission supported drone models, cloud binding, and other settings.
- Parameter configuration: set / get dock configuration parameters through the thing-model interface.

## Edge SDK V2.0.0 Release Notes

### Release Date

2026-06-16

### New Features

- Added support for third-party devices to access the DJI Ground Station via MQTT, allowing devices to forward their own data to the cloud through the DJI Ground Station.
- Added support for RID (Remote ID) device access, enabling the reporting of RID information (rid_infos) and ADS-B information (adsb_infos).
