This section defines the technical standards that third-party devices must meet to access ESDK V2, including network communication, capability set declaration, and message constraints.

## Network and Communication

- The device must support Ethernet and be deployed in the same local area network as the DJI Ground Station.
- The device must support the MQTT protocol and connect to the Broker provided by the DJI Ground Station. The port is fixed at 1883.
- The device must use app_id, app_key, and app_license to complete MQTT authentication. For the concatenation rules, see <a href="../api-reference/mqtt.html#login-information" target="_blank">Access and Authentication - Login Information</a>.

## Capability Set and Topic

- After access, the device must report the capability set once, declaring its own type and supported capabilities through `device_type`.
- The device must subscribe and publish according to the unified Topic rules. The `{client_id}` format is `{app_id}_esdk_{device_id}` (`device_id` is the device's unique identifier, and the sample project uses the device SN by default).
- The device should subscribe to the `state_reply` and `error` Topics to receive the capability set reporting result and exception notifications.

:::warning Note:
The value of `device_type` determines the access identity of the device. **A single device can only declare one `device_type` at a time, not both simultaneously; it cannot be accessed under multiple identities at the same time.** Select the corresponding access method according to your device type: for RID, see <a href="../function-set/rid-access.html" target="_blank">RID Device</a>; for third-party docks, see <a href="../function-set/dock-access/charging.html" target="_blank">Third-Party Dock Device</a>.
:::

## Message Frequency and Payload

The DJI Ground Station imposes the following limits on reporting messages from accessing devices:

| Item | Limit |
|---|---|
| Message Frequency | 5 Hz |
| Single Message Payload | 2048 bytes |

When a limit is exceeded, the DJI Ground Station will intercept the over-limit message and notify the device through the `error` Topic.

:::tip Note:
Only RID devices have a large single report size (up to approximately 20 KB). This limit can be lifted by appending the `@rid` suffix to the end of the username; for details, see <a href="../api-reference/rid.html#payload-extension" target="_blank">Payload Extension</a>. Other devices such as docks do not need to lift this limit.
:::
