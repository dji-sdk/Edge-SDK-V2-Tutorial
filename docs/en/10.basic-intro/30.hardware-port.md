The O4 Ground Station connects to third-party devices via Ethernet ports. This section describes the network ports and configuration of the O4 Ground Station.

:::tip Recommendation:
For initial access and debugging, it is recommended to use the LAN port (right side). The Broker address is fixed at `192.168.50.10:1883`, no additional lookup is required.
:::

:::warning Note:
- `192.168.50.11` is a reserved address for the O4 Ground Station. Connected devices must not use this IP.
- Both ports support PoE power input (PD) and can be powered via a PoE switch; however, the ports do not supply power output (PSE not supported). Connected devices must be powered independently.
:::
