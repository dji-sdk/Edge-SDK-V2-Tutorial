Edge SDK V2 (hereinafter referred to as ESDK V2) is the device access SDK that the DJI Ground Station provides for third-party developers. Based on the standard MQTT protocol, developers can connect their own devices to the DJI Ground Station and interconnect them with the DJI enterprise cloud platform (FlightHub 2) and third-party cloud platforms, quickly integrating third-party devices into the DJI enterprise ecosystem. Typical scenarios such as third-party RID devices and third-party dock devices are already supported.

## Version Differences

| Comparison | ESDK V1 | ESDK V2 |
|---|---|---|
| Hosting Platform | DJI Dock (Dock 3 and earlier) | DJI Ground Station |
| Access Method | C/C++ static library, accessed via private network protocol | MQTT protocol, accessed via open network protocol |
| Development Language | C/C++ | Unrestricted, any language that supports MQTT |
| Supported Features | Live stream subscription, media file retrieval, custom data pass-through | RID/ADS-B data reporting, third-party dock access |

## Supported Features

ESDK V2 currently supports the access of the following two types of devices:

- **RID Device**: Reports the collected drone Remote ID (RID) and aircraft surveillance (ADS-B) data to FlightHub 2 in real time, enabling unified aggregation and visual management of airspace awareness data. For details, see <a href="../function-set/rid-access.html" target="_blank">RID Device</a>.
- **Third-Party Dock**: Works with the DJI Ground Station to implement capabilities such as drone power-on/charging, takeoff and landing coordination, dock configuration, and parameter configuration. For details, see <a href="../function-set/dock-access/charging.html" target="_blank">Third-Party Dock Device</a>.

:::warning Note:
A single device can only use one device type at a time, not both simultaneously; it cannot be accessed under multiple identities at the same time. Please choose the corresponding access method above according to your own device.
:::
