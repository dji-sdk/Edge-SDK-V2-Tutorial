Edge SDK V2 (hereinafter referred to as ESDK V2) is a lightweight open protocol and development toolkit designed for third-party device integration into the DJI enterprise ecosystem. It enables external third-party devices to quickly achieve cloud data transmission, platform integration, and collaborative operations through the DJI Ground Station.

ESDK V2 is built on the open access capabilities of the DJI Ground Station. Developers do not need to rely on edge computing boxes. By simply connecting their devices to the DJI Ground Station via the standard MQTT protocol, device data can be forwarded through the DJI Ground Station to DJI FlightHub 2 for real-time data reporting and cloud collaboration.

## Version Comparison

| Item | ESDK V1 | ESDK V2 |
|---|---|---|
| Hosting Platform | DJI Dock (Dock 3 and earlier) | DJI Ground Station |
| Access Method | C/C++ static library, connected via proprietary network protocol | MQTT protocol, connected via open network protocol |
| Programming Language | C/C++ | Any language that supports MQTT |
| Supported Features | Video stream subscription, media file retrieval, custom data pass-through | RID/ADS-B data reporting (more device types will be supported in the future) |

## RID Feature

ESDK V2 currently supports RID (Remote ID) device access. RID devices can report real-time drone identification (RID) and aircraft surveillance (ADS-B) data to DJI FlightHub 2, enabling unified aggregation and visual management of airspace awareness data.

For details on the RID device access process, reporting rules, and DJI FlightHub 2 visualization configuration, see <a href="../function-set/rid-access.html" target="_blank">RID Feature</a>.

:::tip Note:
RID is the first device type supported by ESDK V2. More device types will be supported in the future, and the access framework will remain consistent.
:::
