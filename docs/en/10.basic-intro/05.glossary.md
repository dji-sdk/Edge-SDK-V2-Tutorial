This section summarizes key terms and abbreviations used in the ESDK V2 developer documentation, helping developers quickly understand the terminology and technical concepts.



| Term | Full Name | Description |
|:---|:---|:---|
| O4 Ground Station | DJI O4 Ground Station | A DJI Ground Station product that serves as the hosting platform for third-party device access via ESDK V2. |
| MQTT | Message Queuing Telemetry Transport | A lightweight publish/subscribe messaging protocol. ESDK V2 uses the MQTT protocol for communication between devices and the DJI Ground Station. |
| Broker | MQTT Broker | An MQTT message broker server responsible for receiving, routing, and distributing messages. The O4 Ground Station has a built-in MQTT Broker for connected devices. |
| Topic | MQTT Topic | An MQTT message subject identifier. Devices subscribe to and publish different Topics to send and receive data. |
| QoS | Quality of Service | The quality of service level in MQTT, defining the reliability guarantee of message delivery. ESDK V2 uses QoS 0 and QoS 1. |
| RID | Remote ID | Remote Identification, a technology used to identify and track drones. RID devices are the first device type supported by ESDK V2. |
| ADS-B | Automatic Dependent Surveillance-Broadcast | A surveillance technology for aircraft that provides position, speed, and other information of nearby aircraft. |
| Capability Set | Capability Set | The type and capability declaration that a device must report after connecting. The DJI Ground Station uses this to identify and process device data. |
| device_type | Device Type | A device type identifier declared in the capability set report. The current `device_type` for RID devices is 7. |
| FlightHub 2 | DJI FlightHub 2 | DJI's enterprise drone management cloud platform, capable of displaying RID / ADS-B target information. |
| GNSS | Global Navigation Satellite System | A global navigation satellite system including GPS, BeiDou, etc., used for device positioning. |
| ICAO | International Civil Aviation Organization | The International Civil Aviation Organization. ADS-B uses a 24-bit ICAO address code to identify aircraft. |
| SN | Serial Number | A serial number used to uniquely identify a device. |
| CONNACK | Connection Acknowledgement | An MQTT connection acknowledgement packet. A return code of 0 indicates a successful connection; 5 indicates authentication failure. |
