本章节列出设备接入 DJI 地面站过程中可能遇到的错误码、含义及对应的处理方式。

## MQTT 连接错误码

设备连接 DJI 地面站 MQTT Broker 时，Broker 通过 CONNACK 报文返回连接结果：

| 返回码 | 含义 | 处理方式 |
|:---:|:---|:---|
| 0 | 连接成功 | 正常流程，可开始订阅 Topic 并上报数据。 |
| 1 | 不可接受的协议版本 | 检查 MQTT 客户端使用的协议版本是否与 Broker 兼容。 |
| 2 | 标识符被拒绝 | 检查 ClientID 是否合法（非空且符合拼接规则）。 |
| 3 | 服务不可用 | DJI 地面站服务暂不可用，稍后重试。 |
| 4 | 用户名或密码格式错误 | 检查 username 和 password 的拼接格式是否正确。 |
| 5 | 认证失败 | app_id / app_key / app_license 校验失败，核对认证信息。 |

## ACL 鉴权错误码

设备接入后，DJI 地面站会对订阅 / 发布的 Topic 及上报消息进行 ACL 校验，校验失败时返回以下错误码（十进制）：

| 错误码 | 含义 | 处理方式 |
|:---|:---|:---|
| 16843008 | 未知的鉴权失败 | 重试连接；若持续失败，核对账号与 Topic 配置。 |
| 16843009 | Topic 不匹配 | 检查 Topic 是否符合 `thing/product/{client_id}/...` 规则。 |
| 16843010 | Topic 中的 client_id 与账号不一致 | 确认 `{client_id}` 与登录账号（`{app_id}_esdk_{设备序列号}`）完全一致。 |
| 16843011 | 订阅的 Topic 不在允许范围 | 仅订阅文档列出的 state_reply / events_reply / requests_reply / services / error 等 Topic。 |
| 16843012 | 发布的 Topic 不在允许范围 | 仅发布文档列出的 state / events / requests / osd / services_reply 等 Topic。 |
| 16843013 | Topic 的 QoS 不匹配 | 按文档要求设置 QoS（如 state / events 使用 QoS 1）。 |
| 16843265 | 消息频率超限 | 上报频率超过 5 Hz，降低上报频率。 |
| 16843266 | 消息长度超限 | 单条消息超过 2048 字节，缩减 payload 体积或通过设备类型声明解除负载限制。 |
