## Edge SDK V2.1.0 发布记录

### 发布日期

2026-10-14

### 新增功能

新增第三方机库设备接入支持，机库可配合 DJI 地面站完成以下能力：
- 开机与充电：支持接入DJI无线充电模块，控制机库内飞机的开关机、开始/停止充电。
- 起降协同：配合地面站完成飞行器起飞、降落与任务异常恢复的准备与进度上报。
- 机库配置：网络参数、上云配置、图传机型切换、上云绑定等配置能力。
- 参数配置：通过物模型接口设置 / 获取机库配置参数。

## Edge SDK V2.0.0 发布记录

### 发布日期

2026-06-16

### 新增功能

- 新增第三方设备通过 MQTT 接入 DJI 地面站的能力，设备可将自身数据经 DJI 地面站转发至云端。
- 新增 RID（Remote ID）设备接入支持，可上报 RID 信息（rid_infos）与 ADS-B 信息（adsb_infos）。
