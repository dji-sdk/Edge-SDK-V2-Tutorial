本章节定义 RID 设备接入 ESDK V2 所涉及的接口，包括负载扩展、能力集上报、RID 信息上报与 ADS-B 信息上报的 payload 结构与字段说明。

## 负载扩展

RID 设备单条 events 上报最大可达约 20 KB，超出 DJI 地面站默认的 2048 字节负载限制。接入时须在 MQTT username 末尾追加 `@rid` 后缀以解除限制，同时能力集上报的 device_type 须为 7，与 username 声明一致。

| 登录信息 | 拼接规则 |
|:---|:---|
| username | `{app_id}_esdk_{设备序列号}@rid` |
| password | 与常规接入一致，无需修改 |

:::warning 注意：
完整的登录信息拼接规则详见 <a href="./mqtt.html#登录信息" target="_blank">接入与鉴权 - 登录信息</a>，RID 设备仅在 username 末尾追加 `@rid`，其余不变。
:::

## 公共字段

以下字段为所有上报消息的顶层通用字段，各接口的字段说明中不再重复列出。

| 字段 | 类型 | 必填 | 说明 |
|:---|:---|:---|:---|
| bid | string | 是 | 业务 ID，非空。 |
| tid | string | 是 | 事务跟踪 ID，非空。 |
| timestamp | integer | 是 | 毫秒时间戳，≥ 0。 |
| version | string | 是 | 协议版本号，固定为 `1.0.0`。 |
| method | string | 否 | 方法标识。events 上报时必填：RID 上报为 `rid_infos`，ADS-B 上报为 `adsb_infos`；state 上报时无此字段。 |
| data | object | 是 | 消息数据主体。 |

## 能力集上报

### Topic

- **Topic**：`thing/product/{client_id}/state`
- **方向**：设备 → DJI 地面站
- **QoS**：1

### Payload 示例

```json
{
  "bid": "UUID-CAPS-XXXX-XXXX",
  "data": {
    "device_type": 7,
    "capabilities": {
      "rid": {
        "supported": true,
        "version": "1.0.0"
      },
      "adsb": {
        "supported": true,
        "version": "1.0.0"
      }
    }
  },
  "tid": "UUID-TRACK-YYYY-YYYY",
  "timestamp": 1757400927326,
  "version": "1.0.0"
}
```

### 字段说明

消息顶层的公共字段说明见 [公共字段](#公共字段)。以下为 data 内的字段：

<div class="collapsible" />

| 字段 | 类型 | 必填 | 说明 |
|:---|:---|:---|:---|
| device_type | integer | 是 | 设备类型。RID 设备固定为 7。 |
| capabilities | object | 是 | 能力集。允许上报空对象 `{}`。 |
| >>rid | object | 否 | RID 能力声明。 |
| >>>>supported | boolean | 否 | 是否支持 RID。 |
| >>>>version | string | 否 | RID 能力版本，如 `1.0.0`。 |
| >>adsb | object | 否 | ADS-B 能力声明。 |
| >>>>supported | boolean | 否 | 是否支持 ADS-B。 |
| >>>>version | string | 否 | ADS-B 能力版本，如 `1.0.0`。 |

### 上报结果

订阅 state_reply 后，能力集上报后将收到 DJI 地面站的回复：

- **Topic**：`thing/product/{client_id}/state_reply`
- **方向**：DJI 地面站 → 设备
- **QoS**：1

```json
{
  "bid": "UUID-CAPS-XXXX-XXXX",
  "data": {
    "result": 0
  },
  "tid": "UUID-TRACK-YYYY-YYYY",
  "timestamp": 1757400927326
}
```

| 字段 | 类型 | 说明 |
|:---|:---|:---|
| result | integer | 处理结果。0 表示成功，其它值表示失败。 |

:::warning 注意：
仅当 result = 0 时，才表示接入成功，可开始上报 RID / ADS-B 事件。
:::

## RID 信息上报

### Topic

- **Topic**：`thing/product/{client_id}/events`
- **方向**：设备 → DJI 地面站
- **QoS**：1
- **method**：`rid_infos`

### Payload 示例

```json
{
  "tid": "UUID-TRACK-YYYY-YYYY",
  "bid": "UUID-CAPS-XXXX-XXXX",
  "timestamp": 1757400927326,
  "method": "rid_infos",
  "version": "1.0.0",
  "data": {
    "capacity_percent": 48,
    "power_supply": 0,
    "gnss": {
      "engine": 0,
      "flag": 2,
      "time": "20250723-142355",
      "lat": 22.58821,
      "lon": 113.50389,
      "alt": 503,
      "satellite": 5,
      "hdop": 5
    },
    "rid": [
      {
        "osid": "1581F6N8C243L0039TB9",
        "rssi": -79,
        "fre": 1,
        "uatype": 2,
        "status": 0,
        "heading": 12,
        "speed": 5.4,
        "uprate": 1.5,
        "lon": 113.22128,
        "lat": 22.58079,
        "altgeo": 120,
        "altbaro": 120,
        "height": 50,
        "op_lon": 113.22322,
        "op_lat": 22.58475,
        "op_alt": 20,
        "uatime": 174462011
      }
    ]
  }
}
```

### 字段说明

消息顶层的公共字段说明见 [公共字段](#公共字段)。以下为 data 内的字段：

<div class="collapsible" />

| 字段 | 类型 | 必填 | 说明 |
|:---|:---|:---|:---|
| capacity_percent | integer | 否 | 上报设备剩余电量百分比，取值范围 [0, 100]。 |
| power_supply | integer | 否 | 供电方式标识。当前协议未定义具体取值含义，如有需要请咨询 DJI 技术支持。 |
| gnss | object | 否 | 上报设备自身的定位信息。 |
| >>engine | integer | 否 | 定位引擎。<ul><li>0：混合定位</li><li>1：GPS 系统</li><li>2：北斗系统</li></ul> |
| >>flag | integer | 否 | 定位标志。<ul><li>0：未定位</li><li>1：SPS 模式</li><li>2：差分模式</li><li>3：PPS 模式</li></ul> |
| >>time | string | 否 | UTC 时间，格式为年月日-时分秒（例：`20250723-142355`）。 |
| >>lat | number | 否 | 纬度。 |
| >>lon | number | 否 | 经度。 |
| >>alt | number | 否 | 海拔高度。 |
| >>satellite | integer | 否 | 定位卫星数。 |
| >>hdop | number | 否 | 水平定位精度因子。 |
| rid | array&lt;object&gt; | 否 | 本次探测到的无人机 Remote ID 目标列表。 |
| >>osid | string | 否 | 无人机 ID。 |
| >>rssi | number | 否 | 信号强度，数值越大代表信号越强。 |
| >>fre | integer | 否 | 通信通道。<ul><li>0：WIFI 5.8G</li><li>1：WIFI 2.4G</li><li>2：蓝牙通道</li></ul> |
| >>uatype | integer | 否 | 无人机类型。<ul><li>0：未知/其他</li><li>1：固定翼飞机</li><li>2：无人机/多旋翼</li><li>3：直升机/旋翼机</li><li>4：垂直起降固定翼</li><li>5：滑翔伞/动力伞</li><li>6：滑翔机</li><li>7：风筝</li><li>8：气球</li><li>9：系留气球</li><li>10：飞艇</li><li>11：降落伞（无动力）</li><li>12：火箭</li><li>13：系留动力飞机</li><li>14：地面障碍物</li><li>15：其他</li></ul> |
| >>status | integer | 否 | 起飞状态。<ul><li>0：未知</li><li>1：地面</li><li>2：空中</li><li>3：紧急</li></ul> |
| >>heading | number | 否 | 航迹角，361 代表未知或悬停状态。 |
| >>speed | number | 否 | 无人机水平速度，单位 m/s。 |
| >>uprate | number | 否 | 无人机垂直速度，单位 m/s。 |
| >>lon | number | 否 | 无人机经度。 |
| >>lat | number | 否 | 无人机纬度。 |
| >>altgeo | number | 否 | 无人机海拔高度，-1000 代表未知。 |
| >>altbaro | number | 否 | 无人机气压高度，-1000 代表未知。 |
| >>height | number | 否 | 无人机距地高度，-1000 代表未知。 |
| >>op_lon | number | 否 | 操作员位置经度。 |
| >>op_lat | number | 否 | 操作员位置纬度。 |
| >>op_alt | number | 否 | 操作员位置高度，单位 m。 |
| >>uatime | number | 否 | 无人机内部时间。 |

:::warning 注意：
gnss 描述上报设备自身的位置；rid[] 中的 lat / lon / op_lat / op_lon 描述被探测无人机及其操作员的位置，两者不可混淆。
:::

## ADS-B 信息上报

### Topic

- **Topic**：`thing/product/{client_id}/events`
- **方向**：设备 → DJI 地面站
- **QoS**：1
- **method**：`adsb_infos`

### Payload 示例

```json
{
  "tid": "4fad3f06-a84e-476a-ba31-1ba330fd5865",
  "bid": "602c4276-f28f-42f9-ab30-4a85072140f5",
  "timestamp": 1777348300100,
  "method": "adsb_infos",
  "version": "1.0.0",
  "data": {
    "capacity_percent": 48,
    "power_supply": 0,
    "gnss": {
      "engine": 0,
      "flag": 2,
      "time": "20260428-035140",
      "lat": 22.793106,
      "lon": 114.358677,
      "alt": 40.9,
      "satellite": 12,
      "hdop": 5
    },
    "adsb": [
      {
        "icao": "781EB7",
        "callsign": "CSN1735",
        "height": 11003,
        "lat": 22.58821,
        "lon": 113.50389,
        "speed": 941,
        "heading": 185,
        "uprate": 0.32
      }
    ]
  }
}
```

### 字段说明

消息顶层的公共字段说明见 [公共字段](#公共字段)。以下为 data 内的字段：

<div class="collapsible" />

| 字段 | 类型 | 必填 | 说明 |
|:---|:---|:---|:---|
| capacity_percent | integer | 否 | 上报设备剩余电量百分比，取值范围 [0, 100]。 |
| power_supply | integer | 否 | 供电方式标识。当前协议未定义具体取值含义，如有需要请咨询 DJI 技术支持。 |
| gnss | object | 否 | 上报设备自身的定位信息。 |
| >>engine | integer | 否 | 定位引擎。<ul><li>0：混合定位</li><li>1：GPS 系统</li><li>2：北斗系统</li></ul> |
| >>flag | integer | 否 | 定位标志。<ul><li>0：未定位</li><li>1：SPS 模式</li><li>2：差分模式</li><li>3：PPS 模式</li></ul> |
| >>time | string | 否 | UTC 时间，格式为年月日-时分秒（例：`20250723-142355`）。 |
| >>lat | number | 否 | 纬度。 |
| >>lon | number | 否 | 经度。 |
| >>alt | number | 否 | 海拔高度。 |
