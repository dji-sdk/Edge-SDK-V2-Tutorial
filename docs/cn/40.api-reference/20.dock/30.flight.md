本章节定义第三方机库配合 O4 地面站完成飞行器起飞、降落与任务异常恢复的 MQTT 接口。与开机充电不同，起降协同为**下行**流程——由地面站通过 services 下发指令，第三方机库应答（services_reply）并通过 event 上报执行进度。作业整体时序（起飞 / 降落 / 异常恢复流程）详见 <a href="../../function-set/dock-access/flight.html" target="_blank">功能集合 - 起降协同</a>。

:::tip 说明：
第三方机库接入后须先完成能力集上报（`device_type = 5`），仅当返回 result = 0 后，才可进行以下交互。详见 <a href="../capability-report.html" target="_blank">能力集上报</a>。
:::

## 协议说明

接口涉及的 Topic 如下：

| 类型 | 方向 | Topic |
|:---|:---|:---|
| 指令下发 | DJI 地面站 → 第三方机库 | thing/product/{client_id}/services |
| 指令应答 | 第三方机库 → DJI 地面站 | thing/product/{client_id}/services_reply |
| 进度上报 | 第三方机库 → DJI 地面站 | thing/product/{client_id}/events |

本章节提供的接口如下：

| 阶段 | 指令（services） | 事件上报（events） |
|:---|:---|:---|
| 起飞准备 | airport_takeoff_prepare | airport_takeoff_prepare |
| 起飞结束 | airport_takeoff_end | airport_takeoff_end |
| 降落准备 | airport_landing_prepare | airport_landing_prepare |
| 降落结束 | airport_landing_end | airport_landing_end |
| 任务异常恢复 | airport_abnormal_recovery | airport_abnormal_recovery |

:::tip 说明：
指令下发与事件上报的 `method` 相同，通过 Topic（services / events）区分消息类型。`output.status` 取值说明见各阶段的「进度上报字段说明」小节。
:::

## 公共字段

以下字段为所有消息的顶层通用字段，各接口不再重复列出。

| 字段 | 类型 | 必填 | 说明 |
|:---|:---|:---|:---|
| bid | string | 是 | 业务 ID，非空 |
| tid | string | 是 | 事务跟踪 ID，非空 |
| timestamp | integer | 是 | 毫秒时间戳，≥ 0 |
| version | string | 是 | 协议版本号，固定为 1.0.0 |
| method | string | 是 | 方法标识 |
| data | object | 是 | 消息数据主体 |
| gateway | string | 否 | 仅出现在指令应答（services_reply）中，值为处理该请求的 O4 地面站（网关）序列号 gateway_sn，由地面站填充，用于标识应答来源。 |

## 起飞准备

### 请求 Payload 示例

- **Topic**：`thing/product/{client_id}/services`
- **方向**：DJI 地面站 → 第三方机库
- **method**：`airport_takeoff_prepare`

```json
{
  "bid": "UUID-CAPS-XXXX-XXXX",
  "tid": "UUID-TRACK-YYYY-YYYY",
  "data": {},
  "method": "airport_takeoff_prepare",
  "version": "1.0.0",
  "timestamp": 1757400927326
}
```

### 请求字段说明

顶层字段见 <a href="#公共字段">公共字段</a>，`data` 为空对象 `{}`，无特有字段。

### 响应 Payload 示例

- **Topic**：`thing/product/{client_id}/services_reply`
- **方向**：第三方机库 → DJI 地面站

```json
{
  "bid": "UUID-CAPS-XXXX-XXXX",
  "data": {
    "output": { "status": "in_progress" },
    "result": 0
  },
  "method": "airport_takeoff_prepare",
  "tid": "UUID-TRACK-YYYY-YYYY",
  "timestamp": 1773816352073,
  "version": "1.0.0",
  "gateway": "gateway_sn"
}
```

### 响应字段说明

顶层字段见 <a href="#公共字段">公共字段</a>，`data` 字段说明如下：

<div class="collapsible" />

| 字段 | 类型 | 说明 |
|:---|:---|:---|
| result | int | 应答结果，非 0 即错误 |
| output | object | 输出 |
| >>status | string | 执行状态。<ul><li>sent：已下发</li><li>in_progress：执行中</li><li>paused：暂停</li><li>ok：成功</li><li>failed：失败</li><li>rejected：拒绝</li><li>canceled：取消</li><li>timeout：超时</li></ul> |

### 进度上报 Payload 示例

- **Topic**：`thing/product/{client_id}/events`
- **方向**：第三方机库 → DJI 地面站

```json
{
  "bid": "UUID-CAPS-XXXX-XXXX",
  "tid": "UUID-TRACK-YYYY-YYYY",
  "data": {
    "result": 0,
    "output": {
      "progress": { "percent": 45 },
      "status": "in_progress"
    }
  },
  "method": "airport_takeoff_prepare",
  "version": "1.0.0",
  "timestamp": 1757400927326
}
```

### 进度上报字段说明

顶层字段见 <a href="#公共字段">公共字段</a>，`data` 字段说明如下：

<div class="collapsible" />

| 字段 | 类型 | 说明 |
|:---|:---|:---|
| result | int | 上报结果，非 0 表示当前阶段失败 |
| output | object | 输出 |
| >>status | string | 执行状态。<ul><li>sent：已下发</li><li>in_progress：执行中</li><li>paused：暂停</li><li>ok：成功</li><li>failed：失败</li><li>rejected：拒绝</li><li>canceled：取消</li><li>timeout：超时</li></ul> |
