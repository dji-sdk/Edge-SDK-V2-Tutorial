本章节定义第三方机库对机库内飞机进行开机 / 关机、开始 / 停止充电的 MQTT 接口。完整充电流程（含前置配置）详见 <a href="../../function-set/dock-access/charging.html" target="_blank">功能集合 - 开机与充电</a>。

:::tip 说明：
- ESDK V2 的开机与充电能力接口须搭配 DJI 无线充电模块使用，无线充电模块由 DJI 提供，如需获取请发送邮件至 [dev@dji.com](mailto:dev@dji.com) 联系 SDK 技术支持团队。
- 第三方机库接入后须先完成能力集上报（`device_type = 5`），仅当返回 result = 0 后，才可下发以下命令。详见 <a href="../capability-report.html" target="_blank">能力集上报</a>。
:::

## 协议说明

接口涉及的 Topic 如下：

| 类型 | 方向 | Topic |
|:---|:---|:---|
| 请求 | 第三方机库 → DJI 地面站 | thing/product/{client_id}/requests |
| 回复 | DJI 地面站 → 第三方机库 | thing/product/{client_id}/requests_reply |

本章节提供的接口如下：

| 操作 | method |
|:---|:---|
| 飞机开机 | drone_open |
| 飞机关机 | drone_close |
| 开始充电 | charge_open |
| 停止充电 | charge_close |

## 公共字段

以下字段为所有消息的顶层通用字段，各接口不再重复列出。

| 字段 | 类型 | 必填 | 说明 |
|:---|:---|:---|:---|
| bid | string | 是 | 业务 ID，非空 |
| tid | string | 是 | 事务跟踪 ID，非空 |
| timestamp | integer | 是 | 毫秒时间戳，≥ 0 |
| version | string | 是 | 协议版本号，固定为 1.0.0 |
| method | string | 是 | 方法标识 |
| data | object | 是 | 消息数据主体 |
| gateway | string | 否 | 仅出现在响应（requests_reply）中，值为处理该请求的 O4 地面站（网关）序列号 gateway_sn，由地面站填充，用于标识响应来源。 |

## 飞机开机

### 请求 Payload 示例

- **Topic**：`thing/product/{client_id}/requests`
- **方向**：第三方机库 → DJI 地面站
- **method**：`drone_open`

```json
{
  "bid": "UUID-CAPS-XXXX-XXXX",
  "tid": "UUID-TRACK-YYYY-YYYY",
  "data": {},
  "method": "drone_open",
  "version": "1.0.0",
  "timestamp": 1757400927326
}
```

### 请求字段说明

顶层字段见 <a href="#公共字段">公共字段</a>，`data` 为空对象 `{}`，无特有字段。

### 响应 Payload 示例

- **Topic**：`thing/product/{client_id}/requests_reply`
- **方向**：DJI 地面站 → 第三方机库

```json
{
  "bid": "UUID-CAPS-XXXX-XXXX",
  "data": {
    "output": { "status": "in_progress" },
    "result": 0
  },
  "method": "drone_open",
  "tid": "UUID-TRACK-YYYY-YYYY",
  "timestamp": 1773816352073,
  "version": "1.0.0",
  "gateway": "gateway_sn"
}
```

### 响应字段说明

顶层字段见 <a href="#公共字段">公共字段</a>，`data` 字段说明如下：

<div class="collapsible" />

| 字段 | 类型 | 说明 |
|:---|:---|:---|
| result | int | 请求结果，非 0 即错误 |
| output | object | 输出 |
| >>status | string | 执行状态。<ul><li>sent：已下发</li><li>in_progress：执行中</li><li>paused：暂停</li><li>ok：成功</li><li>failed：失败</li><li>rejected：拒绝</li><li>canceled：取消</li><li>timeout：超时</li></ul> |
