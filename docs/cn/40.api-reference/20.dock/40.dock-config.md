本章节定义第三方机库配置相关的 MQTT 接口，包括网络配置、图传机型设置与上云配置。

:::tip 说明：
第三方机库接入后须先完成能力集上报（`device_type = 5`），仅当返回 result = 0 后，才可下发以下配置命令。详见 <a href="../capability-report.html" target="_blank">能力集上报</a>。
:::

## 协议说明

接口涉及的 Topic 如下：

| 类型 | 方向 | Topic |
|:---|:---|:---|
| 请求 | 第三方机库 → DJI 地面站 | thing/product/{client_id}/requests |
| 回复 | DJI 地面站 → 第三方机库 | thing/product/{client_id}/requests_reply |

本章节提供的接口如下：

| 操作 | method |
|:---|:---|
| 设置网络配置 | set_network_params |
| 获取网络配置 | get_network_params |
| 设置图传支持的飞机类型 | set_sdr_firmware |
| 获取图传支持的飞机类型 | get_sdr_firmware |
| 上云配置 | set_cloud_params |
| 上云绑定 | airport_organization_bind |

## 公共字段

以下字段为所有消息的顶层通用字段，各接口不再重复列出。

| 字段 | 类型 | 必填 | 说明 |
|:---|:---|:---|:---|
| bid | string | 是 | 业务 ID，非空 |
| tid | string | 是 | 事务跟踪 ID，非空 |
| timestamp | integer | 是 | 毫秒时间戳，≥ 0 |
| version | string | 是 | 协议版本号，固定为 1.0.0 |
| method | string | 是 | 方法标识 |
| data | object | 是 | 消息数据主体 |
| gateway | string | 否 | 仅出现在响应（requests_reply）中，值为处理该请求的 O4 地面站（网关）序列号 gateway_sn，由地面站填充，用于标识响应来源。 |

## 设置网络配置

### 请求 Payload 示例

- **Topic**：`thing/product/{client_id}/requests`
- **方向**：第三方机库 → DJI 地面站
- **method**：`set_network_params`

```json
{
  "bid": "UUID-CAPS-XXXX-XXXX",
  "tid": "UUID-TRACK-YYYY-YYYY",
  "data": {
    "dynamic_ip": true,
    "static_ip_conf": {
      "static_ip": "192.168.1.101",
      "netmask": "255.255.255.0",
      "default_gateway": "192.168.1.1",
      "pri_dns_ip": "192.168.1.100",
      "sec_dns_ip": "192.168.1.100"
    }
  },
  "method": "set_network_params",
  "version": "1.0.0",
  "timestamp": 1757400927326
}
```

### 请求字段说明

顶层字段见 <a href="#公共字段">公共字段</a>，`data` 字段说明如下：

<div class="collapsible" />

| 字段 | 类型 | 说明 |
|:---|:---|:---|
| dynamic_ip | bool | 是否使用动态 IP（DHCP） |
| static_ip_conf | object | 静态 IP 配置（dynamic_ip = false 时生效） |
| >>static_ip | string | 静态 IP 地址 |
| >>netmask | string | 子网掩码 |
| >>default_gateway | string | 默认网关 |
| >>pri_dns_ip | string | 首选 DNS 地址 |
| >>sec_dns_ip | string | 备选 DNS 地址 |

### 响应 Payload 示例

- **Topic**：`thing/product/{client_id}/requests_reply`
- **方向**：DJI 地面站 → 第三方机库

```json
{
  "bid": "UUID-CAPS-XXXX-XXXX",
  "data": { "result": 0 },
  "method": "set_network_params",
  "tid": "UUID-TRACK-YYYY-YYYY",
  "timestamp": 1773816352073,
  "version": "1.0.0",
  "gateway": "gateway_sn"
}
```

### 响应字段说明

顶层字段见 <a href="#公共字段">公共字段</a>，`data` 字段说明如下：

| 字段 | 类型 | 说明 |
|:---|:---|:---|
| result | int | 请求结果，非 0 即错误 |

  "tid": "UUID-TRACK-YYYY-YYYY",
  "data": {},
  "method": "get_network_params",

- **方向**：DJI 地面站 → 第三方机库

```json
{
  "bid": "UUID-CAPS-XXXX-XXXX",
  "data": {
    "result": 0,
    "output": {
      "dynamic_ip": true,
      "static_ip_conf": {
        "static_ip": "192.168.1.101",
        "netmask": "255.255.255.0",
        "default_gateway": "192.168.1.1",
        "pri_dns_ip": "192.168.1.100",
        "sec_dns_ip": "192.168.1.100"
      }
    }
  },
  "method": "get_network_params",
  "tid": "UUID-TRACK-YYYY-YYYY",
  "timestamp": 1773816352073,
  "version": "1.0.0",
  "gateway": "gateway_sn"
}
```

### 响应字段说明

顶层字段见 <a href="#公共字段">公共字段</a>，`data` 字段说明如下：

<div class="collapsible" />

| 字段 | 类型 | 说明 |
|:---|:---|:---|
| result | int | 请求结果，非 0 即错误 |
| output | object | 输出 |
| >>dynamic_ip | bool | 是否使用动态 IP（DHCP） |
| >>static_ip_conf | object | 静态 IP 配置 |
| >>>>static_ip | string | 静态 IP 地址 |
| >>>>netmask | string | 子网掩码 |
| >>>>default_gateway | string | 默认网关 |
| >>>>pri_dns_ip | string | 首选 DNS 地址 |
| >>>>sec_dns_ip | string | 备选 DNS 地址 |

## 上云配置

### 请求 Payload 示例

- **Topic**：`thing/product/{client_id}/requests`
- **方向**：第三方机库 → DJI 地面站
- **method**：`set_cloud_params`

```json
{
  "bid": "UUID-CAPS-XXXX-XXXX",
  "tid": "UUID-TRACK-YYYY-YYYY",
  "data": {
    "cloud_type": 0,
    "mqtt_url": "",
    "mqtt_account": "",
    "mqtt_password": ""
  },
  "method": "set_cloud_params",
  "version": "1.0.0",
  "timestamp": 1757400927326
}
```

### 请求字段说明

顶层字段见 <a href="#公共字段">公共字段</a>，`data` 字段说明如下：

<div class="collapsible" />

| 字段 | 类型 | 说明 |
|:---|:---|:---|
| cloud_type | int | 上云类型。<ul><li>0：司空2</li><li>1：第三方云</li><li>2：司空私有化</li></ul> |
| mqtt_url | string | 上云 MQTT 地址，仅当 cloud_type=1 或 2 时需填写 |
| mqtt_account | string | MQTT 账号，仅当 cloud_type=1 时需填写 |
| mqtt_password | string | MQTT 密码，仅当 cloud_type=1 时需填写 |
