本章节定义第三方机库查询与设置机库物模型（TSL）属性的 MQTT 接口。

:::tip 说明：
第三方机库接入后须先完成能力集上报（`device_type = 5`），仅当返回 result = 0 后，才可读写以下物模型属性。详见 <a href="../capability-report.html" target="_blank">能力集上报</a>。
:::

## 协议说明

接口涉及的 Topic 如下：

| 类型 | 方向 | Topic |
|:---|:---|:---|
| 请求 | 第三方机库 → DJI 地面站 | thing/product/{client_id}/requests |
| 回复 | DJI 地面站 → 第三方机库 | thing/product/{client_id}/requests_reply |

本章节提供的接口如下：

| 操作 | method |
|:---|:---|
| 查询物模型参数 | get_tsl_params |
| 设置物模型参数 | set_tsl_params |

## 公共字段

以下字段为所有消息的顶层通用字段，各接口不再重复列出。

| 字段 | 类型 | 必填 | 说明 |
|:---|:---|:---|:---|
| bid | string | 是 | 业务 ID，非空 |
| tid | string | 是 | 事务跟踪 ID，非空 |
| timestamp | integer | 是 | 毫秒时间戳，≥ 0 |
| version | string | 是 | 协议版本号，固定为 1.0.0 |
| method | string | 是 | 方法标识 |
| data | object | 是 | 消息数据主体 |
| gateway | string | 否 | 仅出现在响应（requests_reply）中，值为处理该请求的 O4 地面站（网关）序列号 gateway_sn，由地面站填充，用于标识响应来源。 |

## 查询物模型参数

### 请求 Payload 示例

- **Topic**：`thing/product/{client_id}/requests`
- **方向**：第三方机库 → DJI 地面站
- **method**：`get_tsl_params`

```json
{
  "bid": "UUID-CAPS-XXXX-XXXX",
  "tid": "UUID-TRACK-YYYY-YYYY",
  "data": {
    "params": ["drone_home_point_longitude", "drone_home_point_latitude"]
  },
  "method": "get_tsl_params",
  "version": "1.0.0",
  "timestamp": 1757400927326
}
```

### 请求字段说明

顶层字段见 <a href="#公共字段">公共字段</a>，`data` 字段说明如下：

| 字段 | 类型 | 说明 |
|:---|:---|:---|
| params | array | 需要获取的属性名数组，属性名见 <a href="#物模型参数表">物模型参数表</a> |

### 响应 Payload 示例

- **Topic**：`thing/product/{client_id}/requests_reply`
- **方向**：DJI 地面站 → 第三方机库

```json
{
  "bid": "UUID-CAPS-XXXX-XXXX",
  "tid": "UUID-TRACK-YYYY-YYYY",
  "data": {
    "result": 0,
    "output": {
      "drone_home_point_longitude": 113.95,
      "drone_home_point_latitude": 22.58
    }
  },
  "method": "get_tsl_params",
  "timestamp": 1757400927326,
  "gateway": "gateway_sn"
}
```

### 响应字段说明

顶层字段见 <a href="#公共字段">公共字段</a>，`data` 字段说明如下：

| 字段 | 类型 | 说明 |
|:---|:---|:---|
| result | int | 请求结果，非 0 即错误 |
| error_reason | string | result 非 0 时，输出对应的错误文案提示用户 |
| output | object | 获取成功的参数集合，如有参数缺失，表示该参数获取失败，字段见 <a href="#物模型参数表">物模型参数表</a> |

## 设置物模型参数

### 请求 Payload 示例

- **Topic**：`thing/product/{client_id}/requests`
- **方向**：第三方机库 → DJI 地面站
- **method**：`set_tsl_params`

```json
{
  "bid": "UUID-CAPS-XXXX-XXXX",
  "tid": "UUID-TRACK-YYYY-YYYY",
  "data": {
    "params": [
      { "drone_home_point_longitude": 113.95 },
      { "drone_home_point_latitude": 22.58 },
      { "station_work_mode": 1 }
    ]
  },
  "method": "set_tsl_params",
  "version": "1.0.0",
  "timestamp": 1757400927326
}
```

### 请求字段说明

顶层字段见 <a href="#公共字段">公共字段</a>，`data` 字段说明如下：

| 字段 | 类型 | 说明 |
|:---|:---|:---|
| params | array | 属性变更数组，每个元素为单键对象 `{属性名: 值}` |

### 响应 Payload 示例

- **Topic**：`thing/product/{client_id}/requests_reply`
- **方向**：DJI 地面站 → 第三方机库

```json
{
  "bid": "UUID-CAPS-XXXX-XXXX",
  "tid": "UUID-TRACK-YYYY-YYYY",
  "data": {
    "result": 0,
    "output": {
      "drone_home_point_longitude": 113.95,
      "drone_home_point_latitude": 22.58,
      "station_work_mode": 1
    }
  },
  "method": "set_tsl_params",
  "timestamp": 1757400927326,
  "gateway": "gateway_sn"
}
```

### 响应字段说明

顶层字段见 <a href="#公共字段">公共字段</a>，`data` 字段说明如下：

<div class="collapsible" />

| 字段 | 类型 | 说明 |
|:---|:---|:---|
| result | int | 请求结果，非 0 即错误 |
| error_reason | string | result 非 0 时，输出对应的错误文案提示用户 |
| output | object | 设置成功的参数集合，如有参数缺失，表示该参数设置失败 |

- 类型列为 `—` 的参数均为只读上报参数（`read_only`），其值由网关通过 OSD 推送，开发者只需读取，无需设置类型。
:::

## charger_state 取值说明

<div class="collapsible" />

| 值 | 含义 |
|:---|:---|
| 0 | 未充电 |
| 1 | 等待充电命令 |
| 2 | 充电中 |
| 3 | 充电完成 |
| 4 | 无法与飞机建立通信 |
| 5 | 输入电压或电池电压无法满足启充条件 |
| 6 | 充电过程中接口板压差过大 |
| 7 | 充电过程中无充电电流 |
| 8 | 电池发生可恢复异常（一般为温度异常） |
| 9 | 电池发生不可恢复异常（一般为温度异常） |
| 10 | 两电池压差过大，且飞机为开机状态 |
| 11 | 电池温度高于起充温度 |
| 12 | 电池不在位 |
| 13 | 电源异常 |
| 14 | 电池加热 |
