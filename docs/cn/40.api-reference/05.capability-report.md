设备完成 MQTT 接入与鉴权后，须先上报一次设备能力集，用于声明设备类型与所支持的能力，DJI 地面站据此完成设备身份识别。本章节定义能力集上报的公共协议，RID 与第三方机库均遵循此协议，仅 `device_type` 与 `capabilities` 的具体内容不同。

`device_type` 决定设备的接入身份，取值如下：

- `device_type = 5`：第三方机库，详见 <a href="./dock/charging.html" target="_blank">三方机库设备</a>
- `device_type = 7`：RID，详见 <a href="./rid.html" target="_blank">RID 设备</a>

:::warning 注意：
同一台设备只能声明一种 `device_type`，不能同时以多种身份接入。
:::

## Topic

- **上报**：`thing/product/{client_id}/state`，方向：设备 → DJI 地面站，QoS 1
- **回复**：`thing/product/{client_id}/state_reply`，方向：DJI 地面站 → 设备，QoS 1

## 公共字段

<div class="collapsible" />

| 字段 | 类型 | 必填 | 说明 |
|:---|:---|:---|:---|
| bid | string | 是 | 业务 ID，非空 |
| tid | string | 是 | 事务跟踪 ID，非空 |
| timestamp | integer | 是 | 毫秒时间戳，≥ 0 |
| version | string | 是 | 协议版本号，固定为 1.0.0 |
| data | object | 是 | 消息数据主体 |
| >>device_type | integer | 是 | 设备类型。<ul><li>5：第三方机库</li><li>7：RID 设备</li></ul> |
| >>capabilities | object | 是 | 能力集，具体字段按设备类型不同，见下方各设备的能力集说明。 |

## 第三方机库的能力集

当 `device_type = 5` 时，`capabilities` 当前上报空对象 `{}` 即可。

```json
{
  "bid": "UUID-CAPS-XXXX-XXXX",
  "tid": "UUID-TRACK-YYYY-YYYY",
  "data": {
    "device_type": 5,
    "capabilities": {}
  },
  "version": "1.0.0",
  "timestamp": 1757400927326
}
```

## RID 设备的能力集

当 `device_type = 7` 时，`capabilities` 用于声明是否支持 RID 与 ADS-B 能力。

```json
{
  "bid": "UUID-CAPS-XXXX-XXXX",
  "data": {
    "device_type": 7,
    "capabilities": {
      "rid": {
        "supported": true,
        "version": "1.0.0"
      },
      "adsb": {
        "supported": true,
        "version": "1.0.0"
      }
    }
  },
  "tid": "UUID-TRACK-YYYY-YYYY",
  "timestamp": 1757400927326,
  "version": "1.0.0"
}
```

<div class="collapsible" />

| 字段 | 类型 | 必填 | 说明 |
|:---|:---|:---|:---|
| capabilities | object | 是 | 能力集。允许上报空对象 `{}`。 |
| >>rid | object | 否 | RID 能力声明。 |
| >>>>supported | boolean | 否 | 是否支持 RID。 |
| >>>>version | string | 否 | RID 能力版本，如 1.0.0。 |
| >>adsb | object | 否 | ADS-B 能力声明。 |
| >>>>supported | boolean | 否 | 是否支持 ADS-B。 |
| >>>>version | string | 否 | ADS-B 能力版本，如 1.0.0。 |

## 上报结果

```json
{
  "bid": "UUID-CAPS-XXXX-XXXX",
  "tid": "UUID-TRACK-YYYY-YYYY",
  "data": { "result": 0 },
  "version": "1.0.0",
  "timestamp": 1757400927326
}
```

| 字段 | 类型 | 说明 |
|:---|:---|:---|
| result | integer | 处理结果。0 表示成功，其它值表示失败。 |

:::warning 注意：
仅当 result = 0 时，才表示能力集生效，之后才能下发/上报各能力域的消息。
:::
