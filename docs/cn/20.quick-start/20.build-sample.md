ESDK V2 提供了一个完整的 RID 接入示例工程，演示设备如何通过 MQTT 连接 DJI 地面站、上报能力集，并上报 RID / ADS-B 信息。本章节介绍如何获取、配置并编译该示例。

## 获取代码包

从代码仓库获取示例工程：

```
git clone https://github.com/dji-sdk/Edge-SDK-V2-Demo
```

:::tip 说明：
后续示例命令均以克隆下来的工程根目录为当前目录。
:::

## 工程目录结构

以下目录结构仅供参考，请以实际获取的代码包为准。

```
sample_esdk2/
├── CMakeLists.txt    // 编译入口（顶层）
├── cmake/            // CMake 模块（定位 mosquitto 等依赖）
├── include/          // 跨模块公共头文件（common / mqtt / rid）
├── src/              // 实现源文件（common / mqtt / rid）
├── third_party/      // 第三方库（nlohmann/json 单头文件）
└── examples/         // 示例程序（rid_report_demo：入口与交互菜单）
```

## 安装依赖

示例基于 mosquitto C++ 客户端实现，编译前先安装依赖（以 Ubuntu / 树莓派为例）：

```bash
sudo apt install -y libmosquittopp-dev cmake build-essential
```

## 开发者信息认证

1. 获取 `app_id`、`app_key`、`app_license`，获取方式见 <a href="./dev-workflow.html#应用注册" target="_blank">开发流程总览 - 应用注册</a>。
2. 修改示例工程中 `include/mqtt/app_info.h` 文件，填写对应的开发者信息：

```c
#define USER_DEVICE_ID      "your_device_id"      // 设备序列号
#define USER_APP_ID         "your_app_id"
#define USER_APP_KEY        "your_app_key"
#define USER_APP_LICENSE    "your_app_license"

// 可选 username 后缀。RID 设备单条消息可超过 2048 字节默认限制，
// 须设为 "@rid" 以解除限制；普通场景留空 ""。
#define USER_USERNAME_SUFFIX "@rid"
```

:::tip 说明：
示例会据此自动拼接 MQTT 登录信息：username / ClientID 格式为 `{app_id}_esdk_{device_id}` + `USER_USERNAME_SUFFIX`，password 格式为 `{app_key}_{app_license}`。完整拼接规则详见 <a href="../api-reference/mqtt.html#登录信息" target="_blank">接入与鉴权 - 登录信息</a>。
:::

## 编译示例代码

在工程根目录下执行：

```bash
mkdir build && cd build && cmake .. && make -j4
```

编译完成后会生成可执行文件 `rid_report_demo`。运行方式详见 <a href="./run-sample.html" target="_blank">运行 Sample</a>。
