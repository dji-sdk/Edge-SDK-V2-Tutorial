本章节介绍接入 ESDK V2 所需的开发环境，包括硬件设备、网络连接、软件依赖与 Broker 地址获取。

## 开发设备

- 一台 DJI O4 地面站，作为设备接入与数据转发的承载平台。
- 一台接入设备或其开发载体（如树莓派等 Linux 设备），用于运行接入程序。
- 一台交换机或路由器，用于将 O4 地面站与接入设备连接在同一局域网下。

## 硬件连接

O4 地面站提供 LAN 口和 WAN 口两个网口，支持以下两种连接方式。网口的详细说明见 <a href="../basic-intro/hardware-port.html" target="_blank">硬件接口</a>。
:::tip 建议：
首次接入与调试时，推荐使用方式一（LAN 口直连），Broker 地址固定，配置最简单。
:::

### 方式一：LAN 口直连

接入设备通过网线直连 O4 地面站的 LAN 口（右侧网口）。接入设备 IP 须位于 `192.168.50.xx` 网段，Broker 地址固定为 `192.168.50.10:1883`，无需额外查询。

<img src="https://terra-1-g.djicdn.com/71a7d383e71a4fb8887a310eb746b47f/esdk-v2/network-topology/LAN-Port.svg" alt="图. ESDK 设备通过 LAN 口直连 O4 地面站" />

### 方式二：WAN 口经路由器

接入设备与 O4 地面站的 WAN 口（左侧网口）分别连入同一台路由器。O4 地面站的 IP 由路由器动态分配，可通过 [Broker 地址获取](#broker-地址获取) 自动获取，或通过行业应用确认。

<img src="https://terra-1-g.djicdn.com/71a7d383e71a4fb8887a310eb746b47f/esdk-v2/network-topology/WAN-Port.svg" alt="图. ESDK 设备经路由器与 O4 地面站组网" />



## 软件安装

接入设备侧需安装 MQTT 客户端依赖。以基于 mosquitto 的开发为例，在 Ubuntu/树莓派系统上执行：

```bash
sudo apt install -y libmosquitto-dev
```

## Broker 地址获取

接入设备上电后，可通过监听 UDP 广播自动获取 O4 地面站的 Broker 地址，无需硬编码 IP。

### 总体流程

1. 接入设备上电，网口通过 DHCP 获取 IP。
2. 设备监听 UDP 端口 `18830`。
3. O4 地面站通过网口每隔约 1 秒广播一次报文。
4. 设备收到广播后解析出其中的 `ip` 字段，使用该 IP 连接 MQTT（端口 `1883`）。
5. 若未接收到广播，可回退至默认地址 `192.168.50.10:1883` 直接连接。

### 广播报文格式

报文为一行 ASCII 文本、UDP 单包，字段间用 `|` 分隔，键值间用 `=` 分隔，不包含换行符与空格，格式非 JSON：

```
MQTTBRK|v=1|id=BMGDNAB0010122|name=O4_Ground_Station|ip=192.168.50.10|seq=32
```

| 字段 | 含义 |
|:---|:---|
| MQTTBRK | 固定魔数头，设备据此识别报文，不符合该格式的报文应忽略。 |
| v | 协议版本，当前为 1。无法识别的版本应忽略该报文。 |
| id | O4 地面站的 SN（唯一 ID），多设备共存时据此筛选目标。 |
| name | 可读名称，仅用于展示，可为空。 |
| ip | 本次广播所在网口的 IP，设备直接用该 IP 连接 MQTT。 |
| seq | 广播序列号，从 0 递增；seq 回到 0 表示 O4 地面站重启，设备应重连。 |

:::warning 注意：
报文不含端口号，Broker 端口固定为 1883。
:::

### 监听参数

| 项目 | 配置 |
|:---|:---|
| 协议 | UDP |
| 端口 | 18830 |
| 绑定地址 | `0.0.0.0`（须绑定通配地址，绑定指定网卡可能导致部分广播无法接收） |
| socket 选项 | `SO_REUSEADDR=1`（须在 bind 之前设置） |
| 接收缓冲 | ≥ 4096 字节 |

### 命令行验证

设备已上电并接入同网段后，可用 tcpdump 确认广播是否到达本机：

```bash
sudo tcpdump -i any udp port 18830 -A
```

正常情况下，终端将持续输出包含 `MQTTBRK|v=1|id=...|name=...|ip=...|seq=...` 的报文内容。
