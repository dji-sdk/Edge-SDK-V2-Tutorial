设备通过 MQTT 接入 DJI 地面站并完成鉴权后，须先上报一次设备能力集，通过 `device_type` 声明自身类型与所支持的能力。这是各类设备接入后的第一步：DJI 地面站据此完成设备身份识别，仅当能力集上报成功后，设备才能进行后续的数据上报与指令交互。

## 上报流程

1. **建立 MQTT 连接**：拼接登录信息并连接 DJI 地面站 Broker，详见 <a href="../api-reference/mqtt.html" target="_blank">接入与鉴权</a>。
2. **订阅回复 Topic**：订阅 `state_reply` 以接收能力集上报结果。
3. **上报能力集**：通过 `state` Topic 上报 `device_type` 与 `capabilities`。
4. **确认结果**：等待 `state_reply` 返回 `result = 0`，表示能力集生效，之后方可下发 / 上报各能力域的消息。

:::warning 注意：
同一台设备只能声明一种 `device_type`，不能同时以多种身份接入。请根据自身设备类型选择对应的接入方式：RID 详见 <a href="./rid-access.html" target="_blank">RID 设备</a>，第三方机库详见 <a href="./dock-access/charging.html" target="_blank">三方机库设备</a>。
:::
