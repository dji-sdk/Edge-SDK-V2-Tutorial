ESDK V2 提供第三方机库配合 O4 地面站完成飞行器**起飞、降落与任务异常恢复**的能力。与开机充电不同，起降协同为**下行**流程——由地面站下发指令给机库，机库执行并上报进度事件。

:::tip 说明：
本能力所指的"起降协同"是**机库配合地面站**做好起降准备并汇报进度，而非控制飞机本身的飞行姿态，飞机的飞行控制由飞机自身完成。
:::

## 功能说明

起降协同包含五个阶段，覆盖起飞、降落与异常恢复三个场景。地面站下发 services 指令后，机库应答并通过 event 上报执行进度，直至完成：

| 阶段 | 说明 | 指令 / 事件上报（method） |
|:---|:---|:---|
| 起飞准备 | 飞行器起飞前的准备 | airport_takeoff_prepare |
| 起飞结束 | 飞行器起飞完成 | airport_takeoff_end |
| 降落准备 | 飞行器降落前的准备 | airport_landing_prepare |
| 降落结束 | 飞行器降落完成 | airport_landing_end |
| 任务异常恢复 | 作业异常时的恢复处理 | airport_abnormal_recovery |

:::tip 说明：
事件上报的 `method` 与下发指令的 `method` 相同，通过 Topic（services / events）区分消息类型。
:::

## 接入流程

起降协同属于第三方机库能力域：

1. **MQTT 接入与鉴权**，详见 <a href="../../api-reference/mqtt.html" target="_blank">接入与鉴权</a>。
2. **能力集上报**（`device_type = 5`），详见 <a href="../../api-reference/capability-report.html" target="_blank">能力集上报</a>。
3. **订阅 services Topic**，接收地面站下发的起降协同指令。
4. **应答并上报进度**：收到 services 后回复 services_reply，随后通过 event 上报执行进度。
