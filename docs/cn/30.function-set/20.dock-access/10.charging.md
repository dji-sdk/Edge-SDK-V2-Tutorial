ESDK V2 提供第三方机库对机库内飞机进行**开机 / 关机、开始 / 停止充电**的能力，共四个操作。

:::tip 说明：
- ESDK V2 的开机与充电能力接口须搭配 DJI 无线充电模块使用，无线充电模块由 DJI 提供，如需获取请发送邮件至 [dev@dji.com](mailto:dev@dji.com) 联系 SDK 技术支持团队。
- 本能力所指的"开机"是**飞机**的开关机，非机库舱盖操作。
:::

## 功能说明

开机与充电包含四个操作，均由第三方机库主动向 O4 地面站发起请求，地面站处理后返回当前状态，采用「请求—回复」交互模型：

| 操作 | 说明 | 命令（method） |
|:---|:---|:---|
| 飞机开机 | 控制机库内飞机开机 | drone_open |
| 飞机关机 | 控制机库内飞机关机 | drone_close |
| 开始充电 | 控制机库对飞机电池开始充电 | charge_open |
| 停止充电 | 控制机库对飞机电池停止充电 | charge_close |

请合理编排命令顺序（如先开机再充电），并在下一步前确认上一条命令回复的 `result` 为 0。

## 接入流程

该能力属于第三方机库能力域，接入步骤如下：

1. **MQTT 接入与鉴权**：拼接登录信息并连接 O4 地面站 Broker，详见 <a href="../../api-reference/mqtt.html" target="_blank">接入与鉴权</a>。
2. **能力集上报**：通过 state Topic 上报设备类型（`device_type = 5`）与能力声明，收到 result = 0 后方可下发命令，详见 <a href="../../api-reference/capability-report.html" target="_blank">能力集上报</a>。
3. **下发开机 / 充电命令**：向 requests Topic 发布对应命令，从 requests_reply 获取结果。

**空调控制条件**

- **制冷启动条件**：电池温度 ≥ 35 ℃ 或 TX 线圈 ≥ 80 ℃ 或 TX MOS ≥ 80 ℃ 或 RX 线圈 ≥ 80 ℃。
- **制热启动条件**：环境温度 < 5 ℃ 且 电池温度 < 35 ℃ 且 TX 线圈 < 80 ℃。
