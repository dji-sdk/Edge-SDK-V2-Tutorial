ESDK V2 提供读写机库物模型（TSL）属性的能力：读取机库实时状态（工作模式、返航点、电池、充电器状态等），并批量设置可写属性。由第三方机库主动向 O4 地面站发起。

## 功能说明

参数配置分查询与设置两个方向，均由第三方机库主动向 O4 地面站发起：

| 操作 | 说明 | 命令（method） |
|:---|:---|:---|
| 查询物模型参数 | 读取机库当前物模型属性值 | get_tsl_params |
| 设置物模型参数 | 批量设置一组可写属性，仅本次提交的属性会被更新 | set_tsl_params |

物模型属性涵盖返航点、备降点、基站工作模式、飞机在位/开机状态、充电状态、电池信息等。完整属性表见 API 介绍章节。

## 可配置参数

通过 `set_tsl_params` 可设置的物模型属性（`read_write` 权限）如下，其余状态类属性为只读上报，完整属性表见 <a href="../../api-reference/dock/thing-model.html#物模型参数表" target="_blank">API 介绍 - 参数配置</a>：

| 属性名 | 作用 | 类型 |
|:---|:---|:---|
| drone_home_point_longitude | 飞机 home 点经度 | double |
| drone_home_point_latitude | 飞机 home 点纬度 | double |
| drone_home_point_height | 飞机 home 点高度 | double |
| drone_alternate_land_point_longitude | 飞机备降点经度 | double |
| drone_alternate_land_point_latitude | 飞机备降点纬度 | double |
| drone_alternate_land_point_height | 飞机备降点高度 | double |
| station_work_mode | 基站工作模式（0：漫游；1：外置机库；2：简易机场） | int |
| third_dock_work_mode | 第三方机库模式，接入第三方机库时须置 1 | int |

:::tip 说明：
- home 点与备降点在机场部署阶段设置一次即可，除非机场发生移动。
- 经纬度、高度等 `double` 类型字段不可用整数传值，否则小数部分会被截断，导致位置数据错误。
:::

## 接入流程

参数配置属于第三方机库能力域：

1. **MQTT 接入与鉴权**，详见 <a href="../../api-reference/mqtt.html" target="_blank">接入与鉴权</a>。
2. **能力集上报**（`device_type = 5`），详见 <a href="../../api-reference/capability-report.html" target="_blank">能力集上报</a>。
3. **查询 / 设置物模型参数**：向 requests Topic 发布 `get_tsl_params` 或 `set_tsl_params`。

:::tip 说明：
接入第三方机库时，须将物模型属性 `third_dock_work_mode` 设为 1。
:::
