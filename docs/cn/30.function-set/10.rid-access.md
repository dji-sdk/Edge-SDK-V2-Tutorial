ESDK V2 支持将第三方 RID/ADS-B 接收设备接入 DJI 地面站，将采集到的无人机身份识别与飞行状态数据实时上报至司空（DJI 行业云平台），实现空域感知数据的统一汇聚与可视化管理。本章节介绍 RID 设备的接入流程、上报频率限制与司空可视化配置。

:::tip 说明：
RID 是 ESDK V2 首个支持的设备类型，能力集上报时 `device_type` 固定为 7。后续将支持更多设备类型，接入框架保持一致。
:::

## 接入流程

1. **MQTT 接入与鉴权**：拼接登录信息并连接 DJI 地面站 Broker，RID 设备须在 username 末尾追加 `@rid` 后缀以解除负载限制，详见 <a href="../api-reference/mqtt.html" target="_blank">接入与鉴权</a>。
2. **能力集上报**：通过 state Topic 上报设备类型与能力声明，收到 result = 0 后方可上报数据，详见 <a href="../api-reference/rid.html#能力集上报" target="_blank">RID 数据上报 - 能力集上报</a>。
3. **数据上报**：将探测到的 RID / ADS-B 目标缓存后批量上报，详见 <a href="../api-reference/rid.html#rid-信息上报" target="_blank">RID 信息上报</a> 和 <a href="../api-reference/rid.html#ads-b-信息上报" target="_blank">ADS-B 信息上报</a>。

## 上报频率限制

DJI 地面站对接入设备的消息频率限制为 5 Hz，超出限制的消息将被拦截。rid_infos 与 adsb_infos 的上报须遵循以下规则：

- 将探测到的目标缓存后合并上报，避免逐条发送。
- rid_infos 与 adsb_infos 各自每隔 2 秒上报一次，将缓存周期内的目标合并到对应的 rid / adsb 数组中一并发送。
- 两类事件相互独立，分别按各自的 2 秒周期上报。

## 司空可视化

RID 设备接入成功后，可在司空的设备运维页面查看 O4 地面站下挂载的 RID 设备：

<img src="https://terra-1-g.djicdn.com/71a7d383e71a4fb8887a310eb746b47f/esdk-v2/rid/device-maintenance.png" />

在司空的设备列表中，O4 地面站下方也会显示已接入的 RID 设备：

<img src="https://terra-1-g.djicdn.com/71a7d383e71a4fb8887a310eb746b47f/esdk-v2/rid/flighthub-device-list-rid.png" width="80%"/>



设备上报的 RID / ADS-B 信息会经 O4 地面站转发至云端，可在司空（DJI 行业云平台）上查看。配置步骤如下：

1. 进入司空项目，依次打开 **「空域安全」→「空域告警」**。
2. 开启 **「DJI O4 地面站」** 空域告警。
3. 在 **「识别类型」** 中选择要展示告警的无人机类型。
4. 设置告警距离阈值。

<img src="https://terra-1-g.djicdn.com/71a7d383e71a4fb8887a310eb746b47f/esdk-v2/rid/flighthub-o4-alert-settings.png" width="80%"/>

完成配置后，司空会在地图上显示告警距离阈值范围内的所有 RID / ADS-B 无人机：

- 以上报内容中的 gnss 信息（即上报设备自身的位置）为**圆心**；
- 以设置的 **「告警距离阈值」** 为**半径**；
- 在该圆形范围内的所有 RID / ADS-B 无人机目标都会显示在地图上。

<img src="https://terra-1-g.djicdn.com/71a7d383e71a4fb8887a310eb746b47f/esdk-v2/rid/flighthub-rid-targets-on-map.png" width="80%"/>



:::tip 提示：
若司空未显示目标，请先确认能力集上报已返回 result=0，且 rid_infos / adsb_infos 按 [上报频率限制](#上报频率限制) 正常上报、未触发频率限制。
:::
