
Edge SDK V2（以下简称 ESDK V2） 是 DJI 地面站面向第三方开发者开放的设备接入 SDK。开发者可基于标准 MQTT 协议，将自有设备接入 DJI 地面站，并实现与 DJI 行业云平台（司空）、第三方云平台联动，快速完成第三方设备与 DJI 行业生态的集成。目前已支持第三方 RID 设备、第三方机库设备等典型场景。

## 版本差异

| 对比项 | ESDK V1 | ESDK V2 |
|---|---|---|
| 承载平台 | 大疆机场（机场 3 及之前） | DJI 地面站 |
| 接入方式 | C/C++ 静态库，通过私有网络协议接入 | MQTT 协议，通过开放网络协议接入 |
| 开发语言 | C/C++ | 不限，任何支持 MQTT 的语言 |
| 支持功能 | 码流订阅、媒体文件获取、自定义数据透传 | RID/ADS-B 数据上报、第三方机库接入 |

## 支持功能

ESDK V2 目前支持以下两类设备接入：

- **RID 设备**：将采集到的无人机身份识别（RID）与航空器监视（ADS-B）数据实时上报至司空，实现空域感知数据的统一汇聚与可视化管理。详见 <a href="../function-set/rid-access.html" target="_blank">RID 设备</a>。
- **第三方机库**：配合 DJI 地面站完成飞机开机/充电、起降协同、机库配置与参数配置等能力。详见 <a href="../function-set/dock-access/charging.html" target="_blank">三方机库设备</a>。

:::warning 注意：
同一台设备只能选择一种设备类型接入，不能同时以多种身份接入。请根据自身设备选择上方对应的接入方式。
:::
