Edge SDK V2（以下简称 ESDK V2）是一套面向第三方设备接入 DJI 行业生态的轻量化开放协议及开发工具集，旨在帮助外部第三方设备借助 DJI 地面站，快速实现数据上云、平台联动及协同作业等功能。

ESDK V2 基于 DJI 地面站开放接入能力。开发者无需依赖边缘计算盒子，只需通过标准 MQTT 协议将自有设备连接至 DJI 地面站，即可将设备数据经 DJI 地面站转发至 DJI 行业云平台（司空），实现数据的实时上报与云端协同。

## 版本差异

| 对比项 | ESDK V1 | ESDK V2 |
|---|---|---|
| 承载平台 | 大疆机场（机场 3 及之前） | DJI 地面站 |
| 接入方式 | C/C++ 静态库，通过私有网络协议接入 | MQTT 协议，通过开放网络协议接入 |
| 开发语言 | C/C++ | 不限，任何支持 MQTT 的语言 |
| 支持功能 | 码流订阅、媒体文件获取、自定义数据透传 | RID/ADS-B 数据上报（后续将支持更多设备类型） |

## RID 功能

ESDK V2 当前支持 RID（Remote ID）设备接入。RID 设备可将采集到的无人机身份识别（RID）与航空器监视（ADS-B）数据实时上报至司空，实现空域感知数据的统一汇聚与可视化管理。

RID 设备的接入流程、上报规则与司空可视化配置详见 <a href="../function-set/rid-access.html" target="_blank">RID 功能</a>。

:::tip 说明：
RID 是 ESDK V2 首个支持的设备类型，后续将支持更多设备类型，接入框架保持一致。
:::
