本章节汇总 ESDK V2 开发文档中涉及的关键术语与缩写，帮助开发者快速理解文档中的专有名词与技术概念。

## 平台与设备

| 术语 | 全称 | 说明 |
|:---|:---|:---|
| O4 地面站 | DJI O4 Ground Station | DJI 地面站产品，ESDK V2 的第三方设备接入承载平台。 |
| 司空 | DJI FlightHub 2 | DJI 行业无人机管理云平台，可展示 RID / ADS-B 目标信息。 |
| 第三方机库 | Third-Party Dock | 泛指接入 ESDK V2 的非 DJI 机库设备，配合 O4 地面站完成飞机开机/充电、起降协同等能力，能力集上报中 device_type = 5。 |
| RID | Remote ID | 远程识别，一种用于标识和追踪无人机的技术。能力集上报中 device_type = 7。 |
| ADS-B | Automatic Dependent Surveillance-Broadcast | 广播式自动相关监视，一种航空器监视技术，可获取周边航空器的位置、速度等信息。 |
| dt5 | Device Type 5 | `device_type = 5` 的简称，表示第三方机库设备。 |
| dt7 | Device Type 7 | `device_type = 7` 的简称，表示 RID 设备。 |
| gateway_sn | Gateway Serial Number | O4 地面站（网关）的序列号。 |
| device_id | Device ID | 接入设备的唯一标识，用于拼接 MQTT 登录信息中的 username / ClientID，格式为 `{app_id}_esdk_{device_id}`。ESDK V2 示例工程默认使用设备 SN 作为 `device_id`。 |

## 接入与协议

| 术语 | 全称 | 说明 |
|:---|:---|:---|
| MQTT | Message Queuing Telemetry Transport | 一种轻量级的发布/订阅消息传输协议，ESDK V2 使用 MQTT 实现设备与 DJI 地面站之间的通信。 |
| Broker | MQTT Broker | MQTT 消息代理服务器，负责接收、路由和分发消息。O4 地面站内置了 MQTT Broker，供接入设备连接。 |
| Topic | MQTT Topic | MQTT 消息的主题标识，设备通过订阅和发布不同的 Topic 来收发数据。 |
| QoS | Quality of Service | MQTT 的服务质量等级，定义消息传输的可靠性保证。ESDK V2 使用 QoS 0 和 QoS 1。 |
| CONNACK | Connection Acknowledgement | MQTT 连接确认报文，返回码 0 表示连接成功，5 表示认证失败。 |
| 能力集 | Capability Set | 设备接入后需上报的自身类型与能力声明，DJI 地面站据此识别和处理设备数据。 |
| device_type | Device Type | 设备类型标识，在能力集上报中声明。第三方机库为 5，RID 设备为 7。同一台设备只能声明一种 device_type，不能同时以多种身份接入。 |
| service / reply / event | Service / Reply / Event | ESDK V2 消息交互的三种角色：service 为下发的服务请求，reply 为对应的响应回复，event 为设备主动上报的事件通知。 |
| bid / tid | Business ID / Transaction ID | bid 为业务 ID，用于标识一次完整业务流程；tid 为事务跟踪 ID，用于关联请求与其对应的回复，排查协议联调问题时可通过比对 tid 确认请求与回复是否配对。 |
| 物模型 / TSL | Thing Specification Language | 描述设备参数与能力的模型定义语言，第三方机库通过物模型接口设置 / 获取机库配置参数。 |
| OSD | On-Screen Display | 物模型只读参数的推送通道，机库的实时状态（电池、充电、线圈等只读属性）由网关通过 OSD Topic 主动推送，开发者只需读取。 |

## 硬件与充电

| 术语 | 全称 | 说明 |
|:---|:---|:---|
| TX 线圈 / RX 线圈 | TX Coil / RX Coil | 无线充电的发射线圈（机库侧，TX）与接收线圈（飞机侧，RX），二者耦合完成无线充电。 |
| ACDC | AC-DC Module | 无线充电系统中的交流转直流供电模块，为 TX 板与充电链路提供电源。 |
| SDR | Software Defined Radio | 软件定义无线电，此处指飞机与 O4 地面站之间的图传链路模块。 |
| CAN-LAN | CAN to LAN Adapter | CAN 总线转局域网的转接器，用于无线充电模块（ACDC）与 O4 地面站之间的通信。 |
| Marker | Marker | 机库停机坪上供飞机识别定位的图案标识，用于辅助精准降落。 |

## 飞行与定位

| 术语 | 全称 | 说明 |
|:---|:---|:---|
| home 点 / 备降点 | Home Point / Alternate Landing Point | home 点为飞机起飞时记录的返航点；备降点为异常情况下的备用降落位置，机场部署阶段设置一次即可。 |
| GNSS | Global Navigation Satellite System | 全球导航卫星系统，包括 GPS、北斗等，用于设备定位。 |
| ICAO | International Civil Aviation Organization | 国际民用航空组织，ADS-B 中使用 24 位 ICAO 地址码标识航空器。 |
