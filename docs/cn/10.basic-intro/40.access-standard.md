本章节定义第三方设备接入 ESDK V2 须满足的技术标准，包括网络通信、能力集声明与消息约束。

## 网络与通信

- 设备须支持以太网，并与 DJI 地面站部署在同一局域网内。
- 设备须支持 MQTT 协议，连接 DJI 地面站提供的 Broker，端口固定为 1883。
- 设备须使用 app_id、app_key、app_license 完成 MQTT 鉴权，拼接规则详见 <a href="../api-reference/mqtt.html#登录信息" target="_blank">接入与鉴权 - 登录信息</a>。

## 能力集与 Topic

- 设备接入后须上报一次能力集，通过 `device_type` 声明自身类型与所支持的能力。
- 设备须按统一的 Topic 规则进行订阅与发布，`{client_id}` 格式为 `{app_id}_esdk_{device_id}`（`device_id` 为设备唯一标识，示例工程默认使用设备 SN）。
- 设备应订阅 `state_reply` 与 `error` Topic，以接收能力集上报结果与异常通知。

:::warning 注意：
`device_type` 的取值决定设备的接入身份，**同一台设备只能声明一种 `device_type`，不能同时以多种身份接入**。请根据自身设备类型选择对应的接入方式：RID 详见 <a href="../function-set/rid-access.html" target="_blank">RID 设备</a>，第三方机库详见 <a href="../function-set/dock-access/charging.html" target="_blank">三方机库设备</a>。
:::

## 消息频率与负载

DJI 地面站对接入设备的上报消息做如下限制：

| 项目 | 限制 |
|---|---|
| 消息频率 | 5 Hz |
| 单条消息负载 | 2048 字节 |

超出限制时，DJI 地面站将拦截超限消息并通过 `error` Topic 通知设备。

:::tip 说明：
仅 RID 设备单条上报体积较大（最大可达约 20 KB），可通过在 username 末尾追加 `@rid` 后缀解除该限制，详见 <a href="../api-reference/rid.html#负载扩展" target="_blank">负载扩展</a>；机库等其它设备无需解除。
:::
