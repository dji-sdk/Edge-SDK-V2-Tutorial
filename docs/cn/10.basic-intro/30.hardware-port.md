O4 地面站通过以太网接口接入第三方设备。本章节介绍 O4 地面站的网络接口及其配置。

:::tip 建议：
首次接入与调试时，推荐使用 LAN 口（右侧），Broker 地址固定为 `192.168.50.10:1883`，无需额外查询。
:::

:::warning 注意：
- `192.168.50.11` 为 O4 地面站保留地址，接入设备不可使用该 IP。
- 两侧网口均支持 PoE 受电（PD），可通过 PoE 交换机为地面站供电；但网口不对外供电（不支持 PSE），接入设备需自行供电。
:::
